# BeMusicSeeker Unofficial Fork

## 概要

本プロジェクトは `Sayaka / 黒皇帝` 氏の [BeMusicSeeker-installer
](https://github.com/SayakaIsBaka/BeMusicSeeker-installer) に含まれる `BeMusicSeeker.exe` を `ILSpy` を用いてデコンパイルし改修/再構築したものです。オリジナルバイナリの作者である [`@rib_2_bit`](https://x.com/rib_2_bit) 氏に無断で行っておりますが、元バイナリはMIT Licenseで公開されているため問題ないと判断しました。ソースコードについては公開されていなかった認識なので、本プロジェクトでも現時点ではリポジトリに含めていません。

## 変更概要

**最も危惧しているのはファイル破壊(DB/BMS)、果たして大丈夫だろうか...?**

1. 初期化高速化
    - `Everything 1.5a` 必須(元実装のファイル列挙もかなり高速だったが1000万ファイル級だと厳しい)
    - ファイル列挙以外にも結構手を入れている(たぶんバグってないはず...)
2. 推定先への移動高速化
    - 遅延の主要因は移動毎のUI更新だったのでバッチ寄りに調整
3. HTTPリクエストにUser-Agentヘッダ付与
    - 一部難易度表サイトで403を起こしていた
4. 難易度表リロード時のタイムアウト延伸30s→300s
    - スプシ管理の譜面数の多い難易度表はレスポンスが遅くなりがちなので30sで足りないケースもあった
5. 左サイドバー上下二段化
    - 難易度表大量だとこの方が使いやすいはず？
6. プレイリストサマリー追加
    - 未所持が増えてもすぐ気が付く、完全所持/未所持有での絞り込みも化、右クリックに単体リロード追加
7. 導入先推定高速化
    - ロジックは完全踏襲しhashなどを使い探索速度強化
8. 同梱追加譜面も差分導入できるようにした
    - 従来、既所持譜面を含むフォルダの場合、未所持譜面のインストール先は推定されなかった
9. スマート上書きモード追加(デフォルトで有効)
    - 同梱音源やBGAなどを古いもので上書きしないように更新日時を確認するようにした
10. 保留画面での実ファイル削除対応
    - インストール済み差分の実ファイルを削除したい要件があるかと思い
11. 差分導入先手動入力許可
    - 既所持BMSフォルダのみ入力許可、推定失敗時用、たまにしか使わない想定なので第二候補をサジェストとかの便利機能はないし、セルを編集しようとクリックしたら再生が始まってしまうことも
12. ポータブルアプリ化
    - 初期起動時に既存のBeMusicSeekerがインストール済みなら設定ファイルを自動で引き継ぐ
13. 推定難易度表/リコメンド表(自動更新含む) 復活
    - 難易度表情報の依存先を [DARKSABUN](https://darksabun.club/) に変更(更新されない前提ならローカルでも良かったかも)

## BASSに関する重要事項

本プロジェクトは、MITライセンスの適用範囲外となるBASS関連のコンポーネントを使用しています。
商用利用には、un4seenからの適切なBASSライセンスの取得が必要です。
Bass.Netラッパーの利用条件については、radio42のライセンスページを参照してください。非商用かつ個人利用の範囲では一定の条件下で許可される場合がありますが、それらの条件はネイティブ版BASSのライセンス条項と共に満たす必要があります。
