## .NET / project 観測

- main project は `Microsoft.NET.Sdk.WindowsDesktop`, `net472`, `UseWPF=True`, `UseWindowsForms=True`。
- test / updater / tools も `net472`。
- `packages.config` は見当たらず、PackageReference と HintPath direct references が混在。
- `libs/*.dll`, `native/*.dll`, `vendor/native/x64/*.dll` を output にコピーする MSBuild target がある。
- root `app.config` には userSettings, probing privatePath, AppContextSwitchOverrides がある。
