# WAVとOGGの同等性判定

統合候補一覧の「衝突WAV/OGGの同等性を検査」が、同名のWAVとOGGを同等と判定する条件の採用理由です。判定の手順としきい値は[WAVとOGGの同等性検査](../spec/library/duplicate-files.md#wavとoggの同等性検査)を正本とします。

## 目的と前提

BMSの作品は、同じ内容をWAV版とOGG版の二つの形式で配布することがあります。両方を一つのフォルダへ統合すると、同じ名前の音源が二つの形式で残ります。この判定は、同名のOGGがWAVからの通常のVorbis変換として説明できるかを波形で確かめ、説明できる名前を「同名音源の拡張子違い」の該当から外します。衝突整理は同等と判定していない名前にも適用するため、この判定は、利用者が整理の前に同等でない衝突を見分ける材料になります（[衝突整理](../spec/library/duplicate-files.md#wavoggの衝突整理)）。

判定は、利用者が持っているWAVとOGGの中身だけを比べます。生成の履歴、タグ、エンコーダー名は入力にしません。非可逆変換では異なる入力が同じ出力になり得るため、「同等」は来歴の証明ではなく、「通常の変換の結果として説明できる」という判定です。

BMSの音源には、数十フレームから数千フレームの短い打音が大量にあります。一つの作品で千を超える組を比べるため、組ごとの処理は一回の走査と少数のフィルタに収めます。

## 基準にした変換

基準は、libvorbisのVBR品質4（代表的なステレオ音源で約128kbps相当）です。BMSのOGG版で広く使われる品質のうち低い側にあたります。これより高い品質は、品質6の変換で同じ条件を満たすことを確かめました。

30作品のWAV 32,173件（すべてステレオ。16ビット・24ビットの整数と32ビット浮動小数点、44.1kHzと48kHz）を、元のレート・チャンネル・長さ・音量のまま品質4で変換した対照を作り、次を確かめました。

- 対照の全件を同等と判定すること（判定を調整する作品と、評価だけに使う作品を、調整の前に半数ずつに分けた）。
- 別のビルドのlibvorbis（品質4と品質6）で変換した2,392件（従来の判定で不合格だった全件を含む）を、全件同等と判定すること。品質3（約112kbps相当）では4件が不合格で、基準より低い品質は保証しません。
- 編集してから同じ条件で変換した音（別の音への差し替え、区間・末尾・片チャンネルの欠落、左右の入替え、音量の変更、位置のずれ、片側だけの無音）と、同じ作品の同じ長さの別名の音の組で、同等と判定する数を従来より増やさないこと。

実際にWAV版とOGG版の両方が配布された30作品（32,169組）では、全名を同等と判定する作品が0から22へ増えました。残る8作品は、長さの違う部分に音があるOGG（ffmpeg内蔵のエンコーダーによる3作品）、64kbps相当のOGG、別の書き出しで長さも波形も合わないOGG、末尾が大きく欠けたOGG、OGGだけが無音の音源、同じ名前に複数のファイルがある音源を含みます。配布物は正しい変換とは限らないため、全作品の同等は目標にしていません。

## 通常の変換で保存される情報と失われる情報

対照の測定から、判定の根拠にできる情報とできない情報を分けました。

| 情報 | 品質4の変換での実測 | 判定での扱い |
| --- | --- | --- |
| 1000Hz以下の波形 | 区間（2048フレーム）ごとの誤差エネルギーは、その区間の1000Hz以下のエネルギーの5%と全帯域の1%の和に、ほぼ収まる。低域の割合が0.1%に満たない音でも保存される | 最も強い根拠。区間別・チャンネル別に見る |
| 4000Hz以下の波形 | 区間ごとの誤差エネルギーは、その区間の4000Hz以下のエネルギーの20%にほぼ収まる。雑音成分の多い打音で誤差が大きい | 1000Hz以下に成分が少ない音の根拠。区間別・チャンネル別に見る |
| 高域の波形 | 雑音成分は波形を保存しない。チャンネル別の全帯域相関は最小で−0.17、両チャンネルを合算しても最小0.58 | 合算した相関0.5以上だけを求め、別の音でないことの確認にとどめる |
| 弱いチャンネルの波形と音量 | 左右を結合して符号化するため、誤差は大きい側のチャンネルに対する相対値で決まる。最大より15dB以上小さいチャンネルでは、音量が5dB変わり、相関が負になる例がある | 波形の誤差はチャンネル間で共通の基準と比べる。音量と区間は、最大の30分の1以上のチャンネルだけ個別に見る |
| 全帯域の音量 | 高域の雑音成分の一部が落ち、最大で3.6dB下がる。上がる側は0.4dBまで | 下限を広く（0.63倍）、上限は狭く（1.15倍）取る |
| 4000Hz以下の音量 | −1.2dBから+0.4dBに収まる | 音量の変更は、この比（0.84〜1.07倍）で見分ける |
| 区間ごとの音量 | 最大の区間の100分の1以上の区間では差が7dBまで。それより小さい区間では、変換が前後へ広げた音や落とした音で、13〜24dBの差が出る | 最大の区間の100分の1以上の区間で−12dBまでを許す |
| 長さ | libvorbisによる変換は、長さを1フレームも変えない | 長さの違いは、末尾が無音の場合だけ許す |

従来の判定（チャンネル別の全帯域相関0.85以上、4000Hz以下の相関0.95以上、音量比0.85〜1.15）は、対照のうち485件を不合格にしていました。全帯域の相関だけが足りない組が435件で、残りは音量比・低域・区間との組合せです。

## 採用した構成

1. **低域の波形を主な根拠にする**：波形が保存される帯域では、区間ごとに誤差を見ます。従来の全体の相関（0.85は誤差エネルギー約28%に相当）より大幅に厳しく、途中や末尾だけが違う音を区別できます。上限は、その区間の低域のエネルギーに比例する項と、同じ区間の全帯域に比例する項（低域が少ない音で、他の帯域の音に隠れる誤差）と、最大の区間に比例する項（静かな区間で変換が落とす音）の和にしました。
2. **全帯域の相関はチャンネルを合算する**：高域が左右で異なる音では、弱い側のチャンネルの高域の位相が保存されません。エネルギーで重み付けした合算の相関は、正しく符号化された大きい側で決まります。
3. **音量は帯域を分けて見る**：全帯域の下限を広げると、3dB程度の音量の変更を全帯域では区別できません。低域の音量は変換でほとんど変わらないため、低域の比で区別します。
4. **区間の端数は独立に見る**：末尾の端数の区間を前の区間へまとめると、音のある末尾の欠落を見逃します。

誤差の上限と各しきい値は、対照の最悪値に対して、波形の条件で約15%、音量と相関の条件で10〜40%の余裕があります。評価だけに使った作品でも全件が収まり、別のビルドの変換でも同じでした。

## 似た音の扱い

BMSの作品では、同名にまとめてもよいほど似た音が、別の名前のまま配布されることが少なくありません。同じ長さの別名の音の組には、同じ素材から別々に書き出した、聴感上は同一の音が含まれます。たとえば、元のWAV同士の相関が0.85で、低域の波形と区間ごとの音量が一致し、高域の細部だけが違う組は、利用者が聞き比べて同一に聞こえることを確かめています。

品質4の変換は、まさに「低域の波形と区間ごとの音量を保ち、高域の細部を変える」処理です。このような組は、信号の比較では正しい変換と区別できません。対照のうち467件は、チャンネル別の全帯域の相関が0.85に届かない正しい変換で、全帯域の相関では、この組と正しい変換を分けられません。したがって、対照の全件を同等にする判定は、この種の「非常によく似た音」も同等にします。この判定は、正しい変換を取りこぼさないことを優先し、聴感上ほぼ同一の音を同等と判定することを受け入れます。

同じ作品・同じ長さの別名の音10,001組で、同等と判定する数は、従来の294組から268組へ減りました。内訳は入れ替わります。元のWAV同士の相関が低域まで下がる組（従来は全体の相関0.85を超えれば通っていた）55組が通らなくなり、高域だけが違う組29組が新たに通ります。

## 長さとレートの扱い

- **末尾が無音の長さ違い**：ffmpeg内蔵のVorbisエンコーダーは、OGGの長さを元と最大で128フレーム短く、1152フレーム長くします。この範囲で、長い側の超過分が完全な無音の場合だけ、共通部分を比べます。超過分に音がある組は、配布物の約3,400組にありましたが、同等にしません。末尾の音の欠落と区別する根拠がないためです。範囲は、実測した44.1kHzと48kHzに限り、他のレートへ換算して広げません。
- **レート違い**：WAVが48kHz、OGGが44.1kHzの作品があります。OGGを160/147の比で48kHzへ変換し、先頭の時刻と音量を保って比べます。変換後の長さとWAVの長さの差は、配布物の656組すべてで1フレーム以内でした。逆向きや他のレートの組合せは、実例を確かめていないため対象にしません。長さを伸縮して合わせる処理と、位置をずらした照合は行いません。位置のずれた音を同等にしないためです。

## 処理時間

2026-11-26に、同じ機械（論理プロセッサ12）・Releaseビルド・同じ入力順で、30作品の検査の合計時間を従来の判定と比べました。機械の負荷の変動を打ち消すため、従来の判定とこの判定を交互に実行しています。

| 入力 | 従来の判定 | この判定 |
| --- | --- | --- |
| 対照（32,173組。すべて同じレート・同じ長さ） | 中央値35.6秒（34.3〜37.5秒、6回） | 中央値35.4秒（34.8〜36.6秒、6回） |
| 配布された30作品（32,169組。レート違い656組を含む） | 33.9〜35.2秒（2回） | 36.2〜36.6秒（2回） |
| 検査オフ（復号しない） | 0.4秒 | 0.4秒 |

対照の検査では、WAVの読取りとOGGの復号が約255 CPU秒、判定が約49 CPU秒です（従来の判定は約63 CPU秒）。1000Hz以下の帯域を加えたため、フィルタの計算量は従来の2倍になりました。WAVとOGGの二つの帯域の列を一つのベクトルで同時に進めることで、判定の時間を従来と同じ水準に収めています。各列の演算の順序は変えていないため、結果は列ごとに計算した場合と一致します。

配布された作品で時間が増えるのは、従来は長さやレートの違いで比べる前に同等でないとしていた組を、最後まで比べるためです。レート違いの長い音源を含む作品が最も遅く、一作品で約4.2秒でした。レート違いの組は、変換後の列（WAVのフレーム数×チャンネル数の倍精度の値）を判定の間だけ保持します。5分の48kHzステレオの音源で約230MBです。

## 採らなかった案

- **しきい値だけを緩める**：全帯域の相関の下限を下げ、低域の相関を0.97に上げる案は、不合格485件のうち190件しか救えません。低域の割合が小さい音と、音量・低域・区間の条件で落ちる音が残ります。
- **従来の条件を残し、新しい条件を追加の合格経路にする**：従来通っていた似た音に、新しく通る似た音が加わり、同等と判定する別名の組が増えます。条件が二系統になり、判定の説明も難しくなります。
- **振幅スペクトルの比較**：波形の位相を使わない比較は、同じ楽器の別の音を区別できません。
- **WAVを再エンコードして比べる**：WAVを同じエンコーダーで変換し直し、復号結果の一致を見る案は、エンコーダーの版と設定が一致する場合にしか成り立ちません。エンコード用のネイティブ依存の追加と、検査時間の増加に見合いません。
- **低い品質に合わせた基準**：64kbps相当のOGGは4000Hz以下の波形も崩れ、同等にする基準は別の音を通します。

## 限界

- 基準より低い品質のOGG、ffmpeg内蔵のエンコーダーで作られたOGGの一部は、同等と判定しません。
- 低域の波形と区間ごとの音量が一致し、高域の細部だけが違う音は、同等と判定します。
- 最大のチャンネルより約15dB以上小さいチャンネルの欠落は、低域の波形の誤差が上限に収まる範囲では区別できません。
- 4000Hz以下にほとんど成分がない音（4000Hz以下のエネルギーが最大のチャンネルの全帯域の1000分の1未満）は、3dB程度の音量の変更を区別できません。
- 途中や末尾の欠落は、欠けた部分が最大の区間の100分の1より小さく、低域の誤差も上限に収まる場合は区別できません。
- 長さの違う組は、超過分に音があれば同等と判定しません。ffmpeg内蔵のエンコーダーで作られたOGG版は、多くがこれに当たります。
