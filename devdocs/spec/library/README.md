# ライブラリ

譜面の読取り、所持状態、ファイル変更と導入を確認します。

| 仕様 | 対象 |
| --- | --- |
| [BMS・BMSONの共通モデル](chart-model.md) | BMSとBMSONを同じ画面・操作から扱うためのモデルと、形式ごとに維持する保存・解析の境界を定めます。 |
| [譜面ファイルの読取り](chart-file-reading.md) | ファイル差分、導入、再走査、LR2同期、補完解析で、譜面のバイト列を重複して読まないための処理分担と寿命を定めます。 |
| [譜面解析の互換性](parser-compatibility.md) | `ChartInfoParser` が採用するBMS・BMSONの解釈と、保存値の比較条件を定めます。 |
| [譜面情報の保存と最新性](chart-info.md) | `chart_info` の識別条件、読込み、補完解析、保存と公開を定めます。 |
| [ライブラリの変更](mutations.md) | 譜面・フォルダ・パッケージを変更する操作について、確認、受付、物理処理、カタログ反映、通知の順序を定めます。 |
| [ファイルとDBの整合](file-db-consistency.md) | ファイルシステムとSQLiteの両方を変更する処理について、保存前の保全、失敗の報告、保証しない範囲を定めます。 |
| [導入先の推定](install-estimation.md) | 保留パッケージや選択譜面について、要求するリソースを最もよく満たす既存フォルダを推定する仕様です。 |
| [ドロップ入力からの導入](drop-install.md) | ファイルのドラッグ＆ドロップを、非同期の導入処理へ安全に引き渡す仕様です。 |
| [重複譜面の確認と整理](duplicate-files.md) | 所持しているBMS・BMSONの重複検索、グループ表示、削除、フォルダ統合を定めます。 |
| [譜面の警告](warnings.md) | 警告の種類、保持する場所、一覧の要約・詳細・強調表示を定めます。 |

[仕様の入口](../README.md)・[共通用語集](../glossary.md)・[設計判断](../../decisions/README.md)へ進みます。
