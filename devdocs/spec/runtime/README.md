# 実行時の管理

起動から終了までの処理、設定、音声の寿命を確認します。

| 仕様 | 対象 |
| --- | --- |
| [起動・初期化・再読込み](startup.md) | ライブラリの構築、操作可能になる条件、必須処理と後続処理、各種再読込みの範囲を定めます。 |
| [初期化・再読込みの進捗](progress.md) | `StartupProgressWorkflowOwner` が管理する進捗、操作の識別、完了の順序、後続処理の表示を定めます。 |
| [設定の編集と反映](settings.md) | 設定画面の編集、保存の受付、取消、変更内容に応じた再読込みを定めます。 |
| [設定ファイルの保存と回復](settings-persistence.md) | ポータブル設定ファイルの読込み、保存、破損時の起動、既存設定の移行を定めます。 |
| [終了と再起動](shutdown.md) | 通常終了、更新、動作モードの変更を共通の終了処理へ接続し、追跡しているDB・ファイル処理と再生の実完了を待つ契約です。 |
| [音声実行基盤と再生](audio.md) | 音声の初期化、機器選択、再生、デバイステスト、解放を定めます。 |
| [音声変換とエンコーダー](audio-conversion.md) | オフライン変換、外部エンコーダーの起動、音量調整、結果と後片付けを定めます。 |
| [音声基盤の依存関係](audio-dependencies.md) | 音声基盤で使用するマネージドパッケージとネイティブDLLの組合せを定めます。 |

[仕様の入口](../README.md)・[共通用語集](../glossary.md)・[設計判断](../../decisions/README.md)へ進みます。
