# 共通基盤

複数の領域が共有する責務、識別、データ規模、並行処理、診断の契約です。機能ごとの入力・結果は各領域の仕様を正本とし、ここではそれらが従う共通の境界を定めます。

| 仕様 | 対象 |
| --- | --- |
| [アーキテクチャ](architecture.md) | アプリケーションの構成、責務の分担、構成が共有する管理主体、実行・配布の境界。 |
| [データと索引](data-and-indexes.md) | 保存データ、所持譜面集合、用途別の索引の所有・識別条件・更新・公開の境界。 |
| [パスによる識別](path-identity.md) | DB行のパスの識別、走査結果への収束、移転に伴う保存値の引継ぎ。 |
| [長いパスとファイル入出力](path-length-and-io.md) | 譜面とリソースの読取り、内部のファイル変更、走査の完全性、長いパスと外部アプリの互換性。 |
| [データ規模と性能](performance-and-scale.md) | 代表規模、全件処理と局所処理、再利用と保存、計測する完了範囲と性能受入。 |
| [ワークフローと並行性](workflow-concurrency.md) | 競合対策の判断手順、受付・実行・完了・公開を分ける共通の設計要件。 |
| [操作の競合ポリシー](operation-concurrency-policy.md) | 操作別の受付領域、開始と終端、並行可否、受理済みの継続、競合拒否と見送り。 |
| [例外・操作結果・診断](exception-handling.md) | 例外の停止範囲、バッチと操作の結果、STATUS、通知と確認、後片付け。 |
| [ログ出力](logging.md) | ログの出力先・レベル・ローテーション、Taskの診断、記録する事実の粒度。 |
| [一時ファイルの管理](managed-temp-files.md) | URL取得とアーカイブ導入で作る一時ファイルの所有範囲と回収の時機。 |

[仕様の入口](../README.md)、[共通用語集](../glossary.md)、[設計判断](../../decisions/README.md)へ進みます。
