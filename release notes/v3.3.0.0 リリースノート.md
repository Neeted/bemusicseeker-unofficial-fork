# 日本語

## 変更点

### 内蔵プレイヤー

- ごく短い音を大量に並べて波形を作る譜面を再生できるようにしました。これまでは再生が一瞬で止まり、停止やアプリの終了もできなくなることがありました。
- 再生の処理が追いつかない譜面は、再生の失敗として停止するようにしました。停止、次の再生、アプリの終了を妨げません。

### 音声ファイルに変換

- 短い音を大量に鳴らす譜面の変換を高速化しました。1フレームの音を約55万回鳴らす譜面では、合成と書出しが約89秒から約0.5秒になりました。
- 「変換中」の進捗ダイアログを、出力先を選んだ直後に開くようにしました。再生中の曲の停止もダイアログの中で行います。
- 進捗ダイアログに、再生の停止、譜面の解析、音源の読込み、音声の合成、ファイルの書出しの段階を表示するようにしました。進捗バーは合成の進み具合に合わせて進みます。
- 音源の読込みと合成の途中でもキャンセルできるようにしました。キャンセルした譜面の書出し途中のファイルは削除し、変換済みのファイルは残します。

### 重複ファイルチェック

- 重複ファイルチェックツリーの先頭に `統合候補一覧` を追加しました。重複グループをフォルダ単位の一覧で表示し、複数のグループをまとめて確認・整理できます。グループごとに、残すフォルダ（`KEEP`）と、確認・整理の対象（`SELECT`）を選びます。検索と並べ替えはグループ単位で行い、条件に一致するグループを除く除外欄もあります。
- 統合候補一覧の `選択グループを確認` は、フォルダの内容を読み取って比較し、統合しても問題がなさそうかを `安全`・`要注意`・`統合不可` で表示します。別内容の同名ファイル、同名音源の拡張子違い、親ディレクトリ参照、同一内容のファイルの共有でつながらないフォルダなどを検出し、理由と該当するファイルをツールチップで確認できます。確認はファイルを変更しません。
- 統合候補一覧の `選択グループを整理` は、選択したグループについて、`KEEP` 以外のフォルダを `KEEP` のフォルダへ統合し、同じフォルダにある重複した譜面を一つだけ残してごみ箱へ移動します。処理中は進捗を表示し、途中でキャンセルできます。終了後に、結果の件数と、完了しなかったグループの理由をまとめて表示します。
- 統合候補一覧の `優先統合先…` で優先するフォルダを登録すると、その配下にあるフォルダがグループ内に一つだけの場合に、そのフォルダを `KEEP` に選びます。
- 右クリックの `マージ先` と `Ctrl + G` によるフォルダのマージは、シンボリックリンクまたはジャンクションを含む場合に、マージせず理由を表示するようにしました。

### 分裂配置チェック

- 左ツリーのメンテナンスに `分裂配置チェック` を追加しました。同じ譜面がなくても、音源のファイル名を多く共有するフォルダを探します。差分譜面だけが別のフォルダに入っている場合など、同じ楽曲が複数のフォルダに分かれて置かれている状態を見つけられます。
- 既定では、どちらのフォルダにも判定に使う音源が 10 個以上あり、音源の少ない方のフォルダの音源名のうち 95% 以上がもう一方にもある組を候補にします。フォルダ直下の `preview`・`_preview`・`__preview` と、10 個を超えるフォルダにある音源名は判定に使いません。同じ譜面があるフォルダは、重複ファイルチェックの対象なので候補にしません。
- 候補は、ツリーの先頭の `統合候補一覧` でまとめて確認・整理できます。操作は重複ファイルチェックの統合候補一覧と同じですが、音源のファイル名だけで候補にしているため、`未確認` のグループは整理できません。先に `選択グループを確認` を実行してください。
- 統合候補一覧の上部で `共有率`・`汎用名とみなすフォルダ数`・`共有率の基準` を選び、`再探索` を押すと、その条件で探索し直せます。選んだ条件はアプリを終了するまで保持します。

## 更新時の注意

- 重複ファイルチェックのマージは、次のいずれかがシンボリックリンクまたはジャンクションの場合に実行できなくなりました。統合して消す側のフォルダとその中のファイル・フォルダ、残す側のフォルダ自体、統合して消す側と同じ位置にある残す側のファイル・フォルダです。リンク先のファイルを移動・削除しないためです。マージする場合は、先にリンクを取り除いてください。

# English

## Changes

### Built-in player

- Charts that build a waveform from a very large number of extremely short sounds can now be played. Previously, playback stopped almost immediately, and stopping playback or closing the app could become impossible.
- When playback processing cannot keep up with a chart, playback now stops as a playback failure. Stopping, starting the next playback, and closing the app are no longer blocked.

### Convert to audio file

- Conversion is much faster for charts that play a large number of short sounds. For a chart that plays one-frame sounds about 550,000 times, synthesis and writing went from about 89 seconds to about 0.5 seconds.
- The "Converting" progress dialog now opens right after you choose the output folder. Stopping the currently playing song also happens inside the dialog.
- The progress dialog now shows the stages: stopping playback, analyzing the chart, loading audio sources, synthesizing audio, and writing the file. The progress bar follows the progress of synthesis.
- You can now cancel while audio sources are loading or audio is being synthesized. The partially written file of the cancelled chart is deleted, and files that were already converted are kept.

### Duplicate file check

- Added `Merge candidates` at the top of the duplicate-file-check tree. It shows duplicate groups as a list of folders and lets you verify and organize several groups together. For each group, you choose the folder to keep (`KEEP`) and whether to verify or organize it (`SELECT`). Search and sorting work by group, and an exclude box removes the groups that match a condition.
- `Verify selected groups` in the merge candidates list reads and compares the contents of the folders and shows whether merging looks safe as `Safe`, `Caution`, or `Cannot merge`. It detects same-name files with different content, same-name audio in different formats, parent directory references, folders that are not connected to the others through files with identical content, and more. The reasons and the files involved are shown in a tooltip. Verification does not change any file.
- `Organize selected groups` in the merge candidates list processes the selected groups: every folder other than `KEEP` is merged into the `KEEP` folder, and for duplicate charts in the same folder, one is kept and the rest are moved to the Recycle Bin. A progress dialog is shown during processing and you can cancel partway. When processing ends, the result counts and the reasons for groups that were not completed are shown together.
- Registering folders with `Preferred destinations...` in the merge candidates list selects a folder under them as `KEEP` when it is the only such folder in its group.
- Merging folders with `Merge to` in the context menu or with `Ctrl + G` is now not performed, and the reason is shown, when a symbolic link or junction is involved.

### Split placement check

- Added `Split placement check` to Maintenance in the left tree. It finds folders that share many audio file names even when they have no chart in common. This helps you find songs whose files are split across several folders, for example when only the additional charts are stored in a separate folder.
- By default, a pair becomes a candidate when each folder has at least 10 audio files used for the comparison and at least 95% of the audio names in the folder with fewer audio files also exist in the other folder. `preview`, `_preview`, and `__preview` directly under a folder, and audio names that exist in more than 10 folders, are not used for the comparison. Folders that contain the same chart are not candidates, because duplicate file check handles them.
- You can verify and organize the candidates together from `Merge candidates` at the top of the tree. The operations are the same as in the merge candidates list of duplicate file check, except that `Unchecked` groups cannot be organized, because candidates are chosen by audio file names only. Run `Verify selected groups` first.
- At the top of the merge candidates list, choose `Share rate`, `Folder count treated as generic names`, and `Share rate basis`, then press `Search again` to search with those conditions. The chosen conditions are kept until you exit the app.

## Notes for updating

- Merging in the duplicate file check can no longer be performed when any of the following is a symbolic link or junction: the folder being merged away and the files and folders inside it, the folder to keep itself, or a file or folder in the folder to keep at the same position as one in the folder being merged away. This prevents files behind the link from being moved or deleted. Remove the link before merging.
