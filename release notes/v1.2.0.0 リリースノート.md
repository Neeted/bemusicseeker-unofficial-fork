# 日本語 v1.2.0.0

## 機能・操作面の変更

### プレイリスト

- プレイリストの `url` / `url_diff` が空の譜面に対して、外部マッピングから URL を補完する機能を追加しました。
  - 補完結果はまずランタイムのインメモリ値として扱われます。補完された URL が見つかると、プレイリスト一覧の `URL1` / `URL2` 列でも既存のダウンロード導線をそのまま使えるようになります。
  - 補完だけでは DB へ即時保存されません。ローカルプレイリストで行編集を保存したときのみ、その時点の補完値も `url` / `url_diff` として保存されます。
  - 外部同期プレイリストの URL 編集制約は従来どおり維持されます。
- URL 補完の設定を追加しました。
  - `プレイリストの url, url_diff が空の場合補完を試みる` を追加しました。デフォルトは有効です。
  - `空ではない url, url_diff も補完機能で上書きする` を追加しました。デフォルトは無効です。
  - `MD5-URLマッピングTSV取得URI` を追加しました。デフォルトでは同梱ではなく外部 URI を参照します。
- `MD5-URLマッピングTSV取得URI` には、HTTP/HTTPS だけでなくローカルの TSV ファイルパスも指定できます。
  - 例えば `C:\bms-md5-url-map.tsv` のようなローカル TSV を指定して、手元で管理しているマッピングを使うことも可能です。
- URI は任意に指定可能です。
  - 将来、より網羅的で高品質な MD5-URL マッピングを配布する提供者が現れれば、その URI を設定することでこの機能はさらに有用になります。
- 補完元として Stella Uploader 由来の URL2 補完も追加しました。
  - `https://stellabms.xyz/score_upload.json` の `md5` と `submission` の対応から `https://stellabms.xyz/upload/{submission}` を組み立て、TSV で見つからなかった譜面の `url_diff` 候補として使います。
- 今回デフォルトで用意した TSV は、主に以下の難易度表や関連ミラーを活用して整備したものです。
  - [旧アプロダ表](https://bms.hexlataia.xyz/tables/olduploader.html)
  - [BMS差分アップローダー表(gnqg)](https://bms.hexlataia.xyz/tables/hinanjoy.html)
  - [Stella Uploader](https://stellabms.xyz/upload.html)

## 不具合修正 / 安定性向上

- プレイリスト URL 補完の取得処理は非同期化し、起動完了や通常のプレイリスト初期化をブロックしないようにしました。
- 起動時だけでなく、外部プレイリストの新規読み込み、個別リロード、全体リロード、設定保存後にも補完の再取得・再適用が走るようにしました。
- TSV と Stella の両方に同じ MD5 がある場合の優先順を固定しました。
  - 常に TSV を優先し、Stella は TSV にない MD5 の `url_diff` 補完だけに使います。
- タイムアウトや取得失敗時のログを追加しました。
  - TSV / Stella ともに 60 秒タイムアウトで処理し、タイムアウト時は WARN ログを残しつつ、アプリ本体はそのまま利用できます。

# English v1.2.0.0

## Feature and usability changes

### Playlist

- Added playlist URL completion for charts whose `url` / `url_diff` are missing.
  - The completed values are first kept as runtime-only in-memory overlays. Once a match is found, the existing `URL1` / `URL2` actions in the playlist detail grid can use those URLs without changing the normal workflow.
  - Completion alone does not immediately write anything to the DB. The completed values are persisted only when a local playlist row is later saved through normal editing.
  - The existing edit restrictions for externally synchronized playlists remain unchanged.
- Added new settings for this feature.
  - `Try to complement playlist url/url_diff when empty` is enabled by default.
  - `Overwrite non-empty url/url_diff with complemented values` is disabled by default.
  - `MD5-URL mapping TSV URI` was added as the configurable source for TSV-based mapping.
- The `MD5-URL mapping TSV URI` can point not only to HTTP/HTTPS resources but also to a local TSV file.
  - For example, you can use a local path such as `C:\bms-md5-url-map.tsv` if you maintain your own mapping file.
- The URI is fully configurable.
  - If a more comprehensive MD5-to-URL mapping source becomes available in the future, pointing this setting to that source will make the feature more useful.
- Added Stella Uploader based URL2 completion.
  - The app reads `md5` and `submission` from `https://stellabms.xyz/score_upload.json`, then builds `https://stellabms.xyz/upload/{submission}` as a `url_diff` candidate for charts that were not matched by the TSV.
- The default TSV prepared for this release was built mainly using data from the following tables and mirrors.
  - [Old uploader table](https://bms.hexlataia.xyz/tables/olduploader.html)
  - [BMS differential uploader table (gnqg)](https://bms.hexlataia.xyz/tables/hinanjoy.html)
  - [Stella Uploader](https://stellabms.xyz/upload.html)

## Bug fixes / stability improvements

- The playlist URL completion fetch pipeline now runs asynchronously so startup and normal playlist initialization do not wait on it.
- Completion refresh and re-apply now run not only at startup, but also after loading a new external playlist, reloading a single playlist, reloading all playlists, and saving related settings.
- Defined a fixed priority order when the same MD5 exists in both sources.
  - TSV always wins, and Stella is used only for `url_diff` completion of MD5s not covered by the TSV.
- Added timeout and failure logging.
  - Both TSV and Stella fetches use a 60-second timeout and emit WARN logs on timeout while keeping the rest of the application usable.
