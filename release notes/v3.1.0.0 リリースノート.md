# v3.1.0.0 リリースノート（草案）

> 未公開版の草案です。バージョン番号は暫定で、v3.0.0.0 から現在の開発版への更新内容をまとめています。
> This is a draft for an unreleased version. The version number is provisional; the notes describe changes from v3.0.0.0 to the current development version.

## 日本語

オーディオ設定を見直し、出力機器が対応する条件の確認とテストを使いやすくしました。再生・音声ファイル変換の処理も共通の Float32 基盤へ整理し、サンプルレート変換の品質設定、変換時の音量処理、失敗理由の表示を改善しています。

### オーディオ設定と出力テスト

- オーディオ設定ページの表示時や、ドライバ・出力デバイスの変更時に、機器の対応情報を自動で確認します。この確認で音を鳴らしたり、通常再生を停止したり、設定を保存したりすることはありません。
- 出力方式に応じて、選択できる条件と機器側で決まる情報を分けて表示します。WASAPI排他では対応するサンプルレートとフォーマットの組合せを候補に反映し、WASAPI共有のミックス設定やASIOの機器形式は読み取り専用の情報として表示します。
- ドライバを変更すると出力デバイスを既定に、サンプルレートとフォーマットを「自動」に戻します。デバイス変更時もレートとフォーマットを「自動」に戻し、レート変更時はフォーマットだけを「自動」に戻します。これらは保存するまで編集中の設定です。
- テストを「再生を停止してテスト」に整理しました。通常再生を止め、選択した条件を確認します。選択した機器・出力方式や、その方式で有効な明示指定のレート・フォーマット・イベント駆動が使えない場合、別の条件で成功したことにはしません。「自動」の条件やバッファ・周期の調整は結果に反映します。
- テスト中は、終了処理が完了するまで設定画面の編集・保存・取消・閉じる操作と重複テストを受け付けません。処理はUIスレッド外で実行します。
- 出力設定、音量、テスト、詳細な音声設定を独立したセクションに整理しました。能力照会とテストに付随する技術的な診断は初期状態で折り畳み、必要に応じて展開できます。指定した条件と実際の出力条件を区別して表示し、初期化や後片付けに失敗した場合も理由を示します。照会・テストの結果で保存設定を上書きすることはありません。

### 再生と音声処理

- 再生と音声ファイル変換で、音源の読込み・チャンネル変換・ミキシングをFloat32へ統一しました。同じ曲で同じ音源を参照する場合の重複した復号を減らしています。
- オーディオの詳細設定に、サンプルレート変換の品質を追加しました。2～6から選択でき、既定値は4です。保存後、次回の再生・テスト・音声ファイル変換から適用します。高い値ほど変換誤差を抑えられますがCPU負荷が増えるため、音切れする場合は低い値を試してください。
- アプリ内の音量を出力方式に共通の処理で適用し、再生中の音量変更は短い時間をかけて滑らかに反映します。
- ASIOでは、32bitの容器に16・18・20・24bitの整数PCMを格納する機器形式に対応しました。機器の形式と内部処理のFloat32を区別して扱います。
- Ogg VorbisのデコーダーをNVorbisからlibvorbisへ変更しました。破損や途中切断の検出も厳密になっています。

### 音声ファイル変換

- 曲を一度レンダーした音声データから、曲全体のピーク・RMSを測定して正規化し、ファイルへ出力する方式に変更しました。発音タイミングと出力長をフレーム単位で扱い、サンプルレート変換後の音源末尾まで書き出します。
- 整数PCMへの最終変換にディザーを適用し、Float32出力では整数化しない構成にしました。
- 正規化や追加増幅の結果が整数入力を必要とする出力形式の範囲を超える場合、音をクリップして保存する代わりに変換失敗として通知します。ピーク値に加え、追加増幅率を下げる目安やPEAK正規化を使う方法を案内します。
- 変換完了時に、失敗した対象と主な理由をまとめて表示します。外部エンコーダーの途中終了や異常な終了コードも、変換成功として扱わないようにしました。
- 選択した出力フォルダーが既に存在しない場合は、通常再生を停止する前に変換要求を拒否します。

### 更新後の注意点

- 破損・途中切断したOgg Vorbis音源は、従来途中まで再生できたものでも読込みに失敗する場合があります。譜面が使用する音源の復号に失敗した場合、その曲の再生・変換を失敗として通知します。
- RMS正規化や大きな追加増幅率を使っていた場合は、変換時の範囲超過の案内を確認してください。Float32 WAVは範囲を超える有限の値も保持できます。
- 音声ファイル変換では、入力音源と曲全体の完成音声データをメモリに保持します。長尺の譜面ではメモリ使用量が増え、扱えるサイズを超える場合は変換に失敗します。

## English

Audio settings now make it easier to inspect device capabilities and test the selected output conditions. Playback and audio-file conversion use a shared Float32 processing foundation, with selectable resampling quality, revised conversion volume handling, and clearer failure messages.

### Audio Settings and Output Tests

- Device capabilities are checked automatically when opening the audio settings page or changing the backend or output device. These checks do not play sound, stop normal playback, or save settings.
- Settings distinguish selectable conditions from information determined by the device. WASAPI exclusive mode offers supported sample-rate and format combinations, while WASAPI shared mix settings and ASIO native device formats are shown as read-only information.
- Changing the backend resets the device to Default and the sample rate and format to Auto. Changing the device resets both rate and format to Auto; changing the rate resets only the format to Auto. These remain edits until you save.
- The test action now stops normal playback and checks the selected conditions. It does not report success through a different device, backend, or explicitly selected rate, format, or event mode when that condition applies to the backend. Auto selections and buffer or period adjustments are reflected in the result.
- Editing, saving, cancelling, closing Settings, and starting another test are disabled until the test and its cleanup finish. The work runs outside the UI thread.
- Output Settings, Volume, Test, and Advanced Audio Settings are separate sections in that order. Technical diagnostics for capability queries and tests are collapsed initially and can be expanded when needed. The page distinguishes requested from actual output conditions, shows initialization and cleanup failure reasons, and never lets capability checks or test results overwrite saved settings.

### Playback and Audio Processing

- Playback and audio-file conversion now share Float32 decoding, channel conversion, and mixing. Repeated references to the same audio source within a song avoid duplicate decoding.
- Added resampling quality to advanced audio settings, with levels 2–6 and a default of 4. Saved changes apply to the next playback, device test, or audio-file conversion. Higher levels reduce conversion error at a greater CPU cost; try a lower level if playback stutters.
- Application volume is applied through a common output stage across backends, with short, smooth transitions when changing volume during playback.
- Added support for ASIO device formats that store 16-, 18-, 20-, or 24-bit integer PCM in a 32-bit container. Native device formats are distinguished from internal Float32 processing.
- Replaced NVorbis with libvorbis for Ogg Vorbis decoding, with stricter detection of damaged or truncated files.

### Audio-file Conversion

- Songs are rendered once, then normalized and encoded from the same completed audio data using whole-song peak and RMS measurements. Note timing and output length are handled in audio frames, including the final source frames after resampling.
- Dither is applied at the final integer PCM conversion stage; Float32 output avoids integer conversion.
- If normalization or additional amplification exceeds the range of an output format requiring integer input, conversion now fails visibly instead of saving clipped audio. The message includes the peak level and guidance on reducing amplification or using PEAK normalization.
- Completion messages summarize failed files and their main causes. Premature encoder termination and abnormal exit codes are also treated as conversion failures.
- If the selected output directory no longer exists, the conversion request is rejected before stopping normal playback.

### Notes When Updating

- Damaged or truncated Ogg Vorbis sources may now fail to load even if they previously played partially. A decoding failure in a source used by the chart is reported as a failure of that song's playback or conversion.
- If you use RMS normalization or high additional amplification, check any range-exceeded guidance during conversion. Float32 WAV can retain finite values outside the integer PCM range.
- Audio-file conversion retains both decoded sources and the completed song audio in memory. Long charts may require more memory, and conversion fails if the supported size is exceeded.
