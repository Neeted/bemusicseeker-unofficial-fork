# 日本語

v3.1.0.0 では、bmson の内蔵再生・録音に対応し、次曲の先読みや発音タイミングの改善で内蔵プレイヤーを強化しました。オーディオ設定と保留パッケージのインストール操作も分かりやすくしています。

## 変更点

### bmson の再生・録音

- bmson の内蔵音声再生と `音声ファイルに変換` に対応しました。bmson 1.0.0 と旧 0.21 を読み込めます。
- BMS と bmson が混在した一覧でも、次曲送り、一時停止、シークを利用できます。

### 内蔵プレイヤー

- 再生中に次の曲を先読みし、連続再生や手動で次曲へ進む際の待ち時間を短縮しました。
- 音源ロードを最適化し、同じ曲で同じ音源を繰り返し読み込む無駄を減らしました。
- 発音タイミングの精度を改善しました。BMS の譜面位置・時刻計算も、記録された数値を正確に扱う方式へ見直しました。
- 再生中の音量変更を滑らかに反映するようにしました。

### オーディオ設定

- 出力設定、音量、テスト、詳細な音声設定の順に画面を整理しました。技術的な診断情報は必要なときに展開できます。
- 出力機器の対応情報を自動で確認し、出力方式に応じて対応するサンプルレートや音声形式を選択・確認しやすくしました。
- テストを `再生を停止してテスト` に整理し、選択した条件での動作と、実際の出力条件を確認できるようにしました。
- サンプルレート変換の品質を 2～6 から選べるようにしました。既定値は 2 です。高い値ほど変換誤差を抑えられますが、CPU 負荷が増えます。保存後、次回の再生・テスト・音声ファイル変換から適用されます。
- `再生時SRC並列度` を 1～4 から選べるようにしました。既定値は 1 です。保存後、次回の再生・テストから適用されます。

### 保留パッケージのインストール

- 導入先候補がある `INSTL DST` セルに `▼` を表示し、候補を選択できることが分かるようにしました（[Issue #12](https://github.com/Neeted/bemusicseeker-unofficial-fork/issues/12)）。
- `警告を無視してインストール` を `新規としてインストール` に変更しました。設定済みの推定先を使用せず、新規インストール先へ導入する操作であることを確認画面でも明示します。
- 導入先が未設定の保留パッケージを新規としてインストールする際にも、既定で確認画面を表示するようにしました。この確認は詳細設定で無効にできます。

### 録音・音声ファイル変換

- 曲全体の音量に基づく正規化へ見直し、録音時の音量調整と音声の書き出し精度を改善しました。
- 変換完了時に、失敗した譜面と主な理由をまとめて表示するようにしました。一部の音源が読み込めず、省略して変換した場合も、対象譜面と省略した音源数を確認できます。

### その他の変更・修正

- ユーザーマニュアルを機能・操作ごとに整理し、設定や操作手順の説明を補いました。
- Ogg Vorbis 音源の読み込みライブラリを NVorbis から libvorbis へ変更しました。
- プレイリスト詳細に、現在の再生・一時停止・停止状態が反映されない問題を修正しました。
- 一部の ASIO 機器が使用する整数 PCM 形式に対応しました。

## 更新後の注意点

- 音声ファイル変換では、RMS 正規化や大きな追加増幅率によって出力形式の音量上限を超えると、変換に失敗する場合があります。表示される案内に従って追加増幅率を下げるか、PEAK 正規化を選択してください。
- `再生時SRC並列度` を 2～4 にすると、音源の末尾がごく短く欠ける既知の問題があります。既定値は 1 で、音声ファイル変換も常に 1 で処理します。

# English

v3.1.0.0 adds built-in bmson playback and audio-file conversion, reduces waits between songs with preloading, and improves note timing. Audio settings and installation controls for pending packages are also easier to use.

## Changes

### bmson Playback and Recording

- Added built-in audio playback and `Convert to audio file` for bmson charts, supporting both bmson 1.0.0 and the older 0.21 format.
- Next-song navigation, pause, and seek work in lists containing both BMS and bmson charts.

### Built-in Player

- The next song is preloaded during playback to reduce waiting when advancing automatically or manually.
- Optimized audio loading to avoid repeatedly loading the same source within a song.
- Improved note timing precision. BMS chart position and timing calculations now handle the recorded numeric values accurately.
- Volume changes during playback now use smooth transitions.

### Audio Settings

- Reorganized the page into Output Settings, Volume, Test, and Advanced Audio Settings, in that order. Technical diagnostics can be expanded when needed.
- Device capabilities are checked automatically, making supported sample rates and audio formats easier to select or inspect for each output backend.
- The `Stop playback and test` action checks the selected conditions and shows the actual output configuration.
- Added selectable resampling quality from 2 to 6, with a default of 2. Higher values reduce conversion error at a greater CPU cost. Saved changes apply to the next playback, device test, or audio-file conversion.
- Added `Playback SRC parallelism` from 1 to 4, with a default of 1. Saved changes apply to the next playback or device test.

### Pending Package Installation

- `INSTL DST` cells with installation candidates now show a `▼` marker to make candidate selection easier to discover ([Issue #12](https://github.com/Neeted/bemusicseeker-unofficial-fork/issues/12)).
- Renamed `Install ignoring warnings` to `Install as new`. The confirmation dialog also explains that this installs into the new-installation destination without using the configured estimated destination.
- Added a confirmation dialog, enabled by default, when installing a pending package as new without a configured destination. This confirmation can be disabled in advanced settings.

### Recording and Audio-file Conversion

- Revised normalization to use whole-song audio levels, improving recording volume adjustment and audio export precision.
- Completion messages now summarize failed charts and their main causes. If some sources could not be loaded and were omitted from a conversion, the message also identifies the chart and the number of omitted sources.

### Other Changes and Fixes

- Reorganized the user manual by feature and operation, and expanded the explanations of settings and procedures.
- Replaced NVorbis with libvorbis for loading Ogg Vorbis sources.
- Fixed playlist details not reflecting the current playing, paused, or stopped state.
- Added support for integer PCM formats used by some ASIO devices.

## Notes When Updating

- Audio-file conversion may fail if RMS normalization or high additional amplification exceeds the output format's level limit. Follow the displayed guidance to reduce amplification or select PEAK normalization.
- `Playback SRC parallelism` values of 2–4 have a known issue where a very short portion of an audio source's tail may be missing. The default is 1, and audio-file conversion always uses 1.
