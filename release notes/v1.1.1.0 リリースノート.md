# 日本語 v1.1.1.0

## 不具合修正 / 安定性向上

- プレイリスト一覧の右クリックメニュー表示を修正しました。
  - 所持譜面では `移動` と `音声ファイルに変換` が従来どおり利用できるように戻しました。
  - 未所持譜面では、ファイル実体がなく実行できない項目をメニューから除外する形に整理しました。
- 起動直後に `移動` 先一覧などが先にルートフォルダ一覧を参照した場合、ライブラリツリーのルートフォルダ子ノードが展開されなくなることがある不具合を修正しました。
  - 親フォルダ候補の責務を整理し、ライブラリ側の候補 cache と ViewModel 側の安定した表示用一覧の更新契約を見直しました。

# English v1.1.1.0

## Bug fixes / stability improvements

- Fixed playlist context menu regressions in the playlist detail view.
  - On owned playlist rows, `Move` and `Convert to audio file` are available again as before.
  - On missing playlist rows, menu items that require a real file and can never run are now removed instead of being shown.
- Fixed an issue where the library tree root-folder child nodes could fail to appear if another UI path, such as the `Move` destination list, read the root-folder list first during startup.
  - The responsibility split was cleaned up so the library owns the candidate cache while the ViewModel owns the stable UI-facing list.
