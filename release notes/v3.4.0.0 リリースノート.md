# 日本語

## 変更点

### 統合候補一覧

- 重複ファイルチェックと分裂配置チェックの統合候補一覧で、同じグループのフォルダ間で `TITLE` 列の値が異なると `STATUS` に `代表TITLE不一致` を表示するようにしました。`ARTIST` 列も同様に `代表ARTIST不一致` を表示します。確認前から表示され、安全性の判定や整理の可否には影響しません。`status:代表TITLE不一致` のように検索欄や除外欄で絞り込めます。
- `STATUS` の補助情報（`WAV/OGG同等`、`代表TITLE不一致`、`代表ARTIST不一致`、`.bmx/.txtの衝突`）を、段階と理由の後ろの一つの括弧に `要注意：同名音源の拡張子違い（代表TITLE不一致, .bmx/.txtの衝突）` のようにカンマ区切りでまとめて表示するようにしました。`.bmx/.txtの衝突` は `安全` のときだけでなく、`要注意` と `統合不可` でも表示します。
- `高速化のための簡易チェック` のラベルを短くし、説明をツールチップへ移しました。
- 検索欄と除外欄に入力補完を付けました。空欄のときに項目の候補を選べ、`status:` に続けて段階や理由、付記を候補から選べます。候補は一覧の表示が0件でも使えます。
- `同名音源の拡張子違い` の警告を、統合によって同じ位置の音源の形式が増える場合だけ表示するようにしました。たとえば一方のフォルダに `foo.wav` だけがあり、もう一方の同じ位置に `foo.ogg` があると、統合後に元の譜面が別の音源を再生する可能性があるため警告します。その名前の音源を持つすべてのフォルダで形式がそろっていれば、警告は出ません。
- `衝突WAV/OGGの同等性を検査` のチェックを追加しました。有効にして `選択グループを確認` を押すと、同名のWAVとOGGが衝突しているときに、OGGがWAVから変換されたものかを波形で判定し、同等と判定された名前を `同名音源の拡張子違い` の警告から外します。衝突したWAVとOGGがすべて同等だったグループは、段階によらず `STATUS` に `WAV/OGG同等` が付きます。確認に時間がかかるため、既定は無効です。
- `衝突整理` の選択（`両方残す`／`OGGを残す`／`WAVを残す`）を追加しました。確認済みのグループで同名のWAVとOGGが衝突した名前について、`選択グループを整理` で一方の形式を `KEEP` のフォルダに残し、もう一方をごみ箱へ移動できます。同等と判定されていない組も対象になり、その場合は確認ダイアログで警告します。既定は `両方残す` です。

# English

## Changes

### Merge Candidates

- In the merge candidates list of the duplicate file check and the split placement check, `Representative TITLE mismatch` now appears in `STATUS` when folders in the same group show different values in the `TITLE` column. The same applies to `ARTIST`, shown as `Representative ARTIST mismatch`. These notes appear before verification and do not affect the safety rating or whether the group can be organized. You can filter by them in the search or exclusion box, for example with `status:"Representative TITLE mismatch"`.
- Supplementary notes in `STATUS` (`WAV/OGG equivalent`, `Representative TITLE mismatch`, `Representative ARTIST mismatch`, and `.bmx/.txt collision`) now appear together in one pair of parentheses after the stage and reasons, separated by commas, as in `Caution: same audio name, different extension (Representative TITLE mismatch, .bmx/.txt collision)`. `.bmx/.txt collision` now appears for `Caution` and `Cannot merge` as well as `Safe`.
- Shortened the `Quick check for speed` label and moved its explanation to the tooltip.
- Added suggestions to the search and exclusion boxes. When a box is empty, you can choose from the available fields, and after `status:`, you can choose a stage, reason, or note. Suggestions are available even when the list shows no results.
- The `same audio name, different extension` warning now appears only when merging would add a format for audio at the same relative location. For example, if one folder has only `foo.wav` and another has `foo.ogg` at the same relative location, a chart may play a different audio file after merging, so the warning appears. If every folder containing that audio name already has the same set of formats, the warning does not appear.
- Added the `Check WAV/OGG collisions for equivalence` check. When it is enabled and you press `Verify selected groups`, a same-name WAV and OGG that collide are compared by waveform to judge whether the OGG was converted from the WAV, and names judged equivalent no longer trigger the `same audio name, different extension` warning. A group whose colliding WAV and OGG files were all judged equivalent gets the `WAV/OGG equivalent` note in `STATUS` at any stage. It is disabled by default because verification takes longer.
- Added the `Collision cleanup` choice (`Keep both` / `Keep OGG` / `Keep WAV`). For each colliding same-name WAV and OGG in verified groups, `Organize selected groups` can keep one format in the `KEEP` folder and move the other to the Recycle Bin. Pairs not judged equivalent are included too, and the confirmation dialog warns about them. The default is `Keep both`.
