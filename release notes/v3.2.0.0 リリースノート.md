# 日本語

v3.2.0.0 では、譜面のリソース不足や未使用定義を確認できる「譜面プロパティ」を追加しました。拡大縮小率の異なる複数のモニターでランプビューアを使う際の配置と描画も改善しました。

## 変更点

### 譜面プロパティ

- 一覧の右クリックメニューに `譜面プロパティ` を追加しました。ローカルに実ファイルのある譜面を1件選んで開けます。保留パッケージ内の譜面にも対応しています。
- BMS・PMS・bmsonの不足・確認不能なファイル、未使用リソース定義、未定義参照番号を確認できます。STAGEFILE・BACKBMP・BANNERなどの補助画像も不足確認の対象です。
- BMS・PMSは `#WAV01 file.wav` などのコマンド風の表記で、bmsonは本来の項目名で表示します。表示された文字は選択してコピーできます。

### ランプビューア

- Windowsの拡大縮小率がモニターごとに異なる環境で、メインウィンドウから離れた位置や画面外に開く問題を修正しました。
- メインウィンドウの中央を基準に開き、表示先の作業領域に合わせて位置と大きさを調整するようにしました。
- 拡大縮小率の異なるモニターへ移動した際に、文字の表示幅やグラフ内のラベルを更新するようにしました。選択・スクロール位置・表示モードは維持します。
- タスクバーからランプビューアを直接選択できるようにしました。

### 診断ログ

- 起動時のアプリ・Windowsのバージョンやモニター構成・拡大縮小率を `log/application.log` に記録し、表示の問題を調べやすくしました。
- 予期しないエラーの記録先をローカルのログへ統一し、自動送信を行わないようにしました。

# English

v3.2.0.0 adds Chart properties to inspect missing resources and unused definitions. It also improves Lamp Viewer positioning and rendering when using multiple monitors with different display scaling settings.

## Changes

### Chart Properties

- Added `Chart properties` to the list context menu. Select one chart with a local file to open it, including charts inside pending packages.
- Inspect missing or unverifiable files, unused resource definitions, and undefined reference numbers in BMS, PMS, and bmson charts. Auxiliary images such as STAGEFILE, BACKBMP, and BANNER are also checked for missing files.
- BMS and PMS entries use command-style notation such as `#WAV01 file.wav`, while bmson entries use their native field names. Displayed text can be selected and copied.

### Lamp Viewer

- Fixed the viewer opening far from the main window or off-screen when Windows display scaling differs between monitors.
- The viewer opens centered on the main window, with its position and size adjusted to fit the destination monitor's work area.
- Text measurements and labels inside graphs now update when moving the viewer between monitors with different scaling settings. Selection, scroll position, and display mode are preserved.
- The viewer can now be selected directly from the taskbar.

### Diagnostic Logs

- App and Windows versions, monitor configuration, and display scaling are now recorded in `log/application.log` at startup to help investigate display issues.
- Unexpected errors are now recorded in local logs without automatic transmission.
