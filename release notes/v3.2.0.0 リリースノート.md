# 日本語

v3.2.0.0 では、保留画面で導入後のリソース状態や導入先が自動確定されない理由を確認しやすくしました。譜面のリソース不足や未使用定義を確認できる「譜面プロパティ」を追加し、拡大縮小率の異なる複数のモニターでランプビューアを使う際の配置と描画も改善しました。

> [!IMPORTANT]
> **保存済みの健康度を新しい計算基準へ更新するには、再スキャンが必要です。**
>
> アプリを更新しただけでは、保存済みの件数は新しい使用ファイル基準で再集計されません。必要に応じて、`ファイルスキャン` → `全譜面を再スキャン` を実行してください。

## 変更点

### インストール先推定

- `マージ先を推定` を廃止し、`インストール先を推定` に統一しました。既所持譜面だけのパッケージも、同じ操作で推定できます。
- 同梱リソースを導入先のファイルと合わせて評価する仕組みは従来どおりです。同梱分を含めた充足率が同じ場合は、譜面で使用するファイルが既に多くそろっている候補を優先するようにしました。

### インストール

- 保留画面の健康度とリソース不足警告を、設定した導入先、未設定なら先頭候補へ同梱リソースを配置した場合の状態で表示するようにしました。WAV・BGA・MOVIEに加え、STAGEFILE・BACKBMP・BANNERも同じ基準で確認できます。導入先を設定した後も、不足があれば警告を表示します。
- 推定対象全体の音源が導入後も不足する、または完全性を確認できず導入先の自動確定を見送った場合に、`導入後音源不足` / `導入後音源未確認` を表示し、行を警告色にするようにしました。`TITLE/ARTIST未確認` と同時に表示できます。推定時の理由は手動で導入先を変えても残り、再推定で更新されます。
- 保留画面から開く `譜面プロパティ` も同じ配置基準でリソースを確認し、確認基準と確認先を表示するようにしました。

### リソース健康度

- `WAV`・`BGA`・`MOVIE` の計算対象を、`#WAV`・`#BMP` の定義全体から、譜面内で使用が指定されたファイルへ変更しました。未使用の定義は数えず、同じファイルを複数の定義番号で参照していても1件として扱います。
- パーセンテージを「存在するファイル数 ÷ 使用するファイル数 × 100」に変更し、従来の不足時の追加減点をなくしました。例えば、使用ファイル4件のうち3件があれば75%です。不足が残っている場合は100%と表示しません。
- 使用ファイルがない種類は `-` と表示します。定義のない参照番号による無音ノーツなどは、不足に含めません。

### 譜面プロパティ

- 一覧の右クリックメニューに `譜面プロパティ` を追加しました。ローカルに実ファイルのある譜面を1件選んで開けます。保留パッケージ内の譜面にも対応しています。
- BMS・PMS・bmsonの不足・確認不能なファイル、未使用リソース定義、未定義参照番号を確認できます。STAGEFILE・BACKBMP・BANNERなどの補助画像も不足確認の対象です。
- BMS・PMSは `#WAV01 file.wav` などのコマンド風の表記で、bmsonは本来の項目名で表示します。表示された文字は選択してコピーできます。

### ランプビューア

- Windowsの拡大縮小率がモニターごとに異なる環境で、メインウィンドウから離れた位置や画面外に開く問題を修正しました。
- メインウィンドウの中央を基準に開き、表示先の作業領域に合わせて位置と大きさを調整するようにしました。
- 拡大縮小率の異なるモニターへ移動した際に、文字の表示幅やグラフ内のラベルを更新するようにしました。選択・スクロール位置・表示モードは維持します。
- タスクバーからランプビューアを直接選択できるようにしました。

### プレイリストのインポート

- プレイリストツリーのルートを右クリックして開く `プレイリストをインポート` に、難易度表リスト・内蔵表・URL／ファイルからの読み込みをまとめました。複数の入力元から選んだ表を右側の一覧で確認し、一度にインポートできます。
- 難易度表を名前・記号・分類・URLの部分一致で検索できるようにしました。分類単位や検索結果全体の選択・解除、登録済みURLや同名候補の非表示にも対応しています。タブや検索条件を変えても選択は残ります。
- 外部候補は表名の直前の分類を折りたたんで表示し、分類を展開した長い一覧も滑らかにスクロールできるようにしました。
- インポート直前に登録済みのページURL・ヘッダーURLを再確認し、同じURLの読み込みを省くようにしました。除外や失敗がある場合は、成功・同URL・同名・失敗の件数と対象を結果画面で確認できます。

### 診断ログ

- 起動時のアプリ・Windowsのバージョンやモニター構成・拡大縮小率を `log/application.log` に記録し、表示の問題を調べやすくしました。
- 予期しないエラーの記録先をローカルのログへ統一し、自動送信を行わないようにしました。

# English

v3.2.0.0 makes it easier to check resource availability after installation and understand why a destination was not set automatically in the pending view. It also adds Chart properties to inspect missing resources and unused definitions, and improves Lamp Viewer positioning and rendering when using multiple monitors with different display scaling settings.

> [!IMPORTANT]
> **Rescan charts to update saved resource health to the new calculation basis.**
>
> Updating the app does not automatically recalculate saved resource counts using the new used-file basis. As needed, run `File scan` → `Rescan all charts` to update them.

## Changes

### Installation Destination Estimation

- Removed `Estimate merge destination` and unified it with `Estimate install destination`. The same command can also estimate destinations for packages containing only charts you already own.
- Bundled resources are still evaluated together with files at each candidate destination. When availability including bundled resources is equal, candidates that already contain more of the files used by the chart are now preferred.

### Installation

- Resource health and missing-resource warnings in the pending view now reflect the configured destination, or the first candidate when no destination is set, including bundled resources that would be installed there. The same basis applies to WAV, BGA, MOVIE, STAGEFILE, BACKBMP, and BANNER. Missing-resource warnings remain visible after setting a destination.
- Added `Audio missing after installation` / `Audio after installation unverified` warnings and highlighted rows when automatic destination selection is withheld because audio would remain missing or its completeness cannot be verified for the estimated group. These warnings can appear alongside `TITLE/ARTIST unconfirmed`. The reasons recorded during estimation remain after manual destination changes and are updated by a new estimation.
- `Chart properties` opened from the pending view uses the same resource placement basis and displays the verification basis and path.

### Resource Health

- `WAV`, `BGA`, and `MOVIE` now count files used by the chart rather than all `#WAV` and `#BMP` definitions. Unused definitions are excluded, and the same file is counted once even when referenced through multiple definition numbers.
- Percentages now use “existing files ÷ used files × 100,” without the previous additional penalty for missing files. For example, three existing files out of four used files gives 75%. A category with missing files is never displayed as 100%.
- Categories with no used files display `-`. Undefined reference numbers, such as those used for silent notes, do not count as missing files.

### Chart Properties

- Added `Chart properties` to the list context menu. Select one chart with a local file to open it, including charts inside pending packages.
- Inspect missing or unverifiable files, unused resource definitions, and undefined reference numbers in BMS, PMS, and bmson charts. Auxiliary images such as STAGEFILE, BACKBMP, and BANNER are also checked for missing files.
- BMS and PMS entries use command-style notation such as `#WAV01 file.wav`, while bmson entries use their native field names. Displayed text can be selected and copied.

### Lamp Viewer

- Fixed the viewer opening far from the main window or off-screen when Windows display scaling differs between monitors.
- The viewer opens centered on the main window, with its position and size adjusted to fit the destination monitor's work area.
- Text measurements and labels inside graphs now update when moving the viewer between monitors with different scaling settings. Selection, scroll position, and display mode are preserved.
- The viewer can now be selected directly from the taskbar.

### Playlist Import

- Combined the table list, built-in tables, and URL / file input in the `Import playlists` window, opened from the playlist tree root's context menu. Review tables selected from multiple sources in the list on the right and import them together.
- Added substring search by table name, symbol, category, or URL. Select or clear a category or all search matches, and hide registered URLs or candidates with existing names. Selections remain when changing tabs or search conditions.
- External candidates start with the categories immediately above table names collapsed. Long lists scroll smoothly even with categories expanded.
- Registered page and header URLs are checked again before import, avoiding duplicate loads. When items are skipped or fail, the result dialog shows separate counts for successful imports, duplicate URLs, duplicate names, and failures, along with samples of the affected items.

### Diagnostic Logs

- App and Windows versions, monitor configuration, and display scaling are now recorded in `log/application.log` at startup to help investigate display issues.
- Unexpected errors are now recorded in local logs without automatic transmission.
