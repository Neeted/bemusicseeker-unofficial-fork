# 日本語

v3.2.0.0 では、インストール先の推定をより高精度にし、取り込み後の自動推定で導入先が確定したパッケージを自動でインストールできるようにしました。

リソース健康度は、従来の `#WAV`・`#BMP` の定義数ではなく譜面内で実際に使用するファイルを基準に計算するようにしました。未使用の定義を除外するため、より信頼性の高い値になります。

このほか、設定、外観テーマ、一覧、ランプビューアなどの画面を調整しました。

> [!IMPORTANT]
> **保存済みの健康度を新しい計算基準へ更新するには、再スキャンが必要です。**
>
> アプリを更新しただけでは、保存済みの件数は新しい使用ファイル基準で再集計されません。必要に応じて、`ファイルスキャン` → `全譜面を再スキャン` を実行してください。

## 変更点

### インストール先推定

- `マージ先を推定` を廃止し、`インストール先を推定` に統一しました。既所持譜面だけのパッケージも、同じ操作で推定できます。
- 推定の計算方法を見直し、同梱リソースの多い本体パッケージも、同梱リソースの少ない差分作品も、同じ方法で導入先を判断できるようにしました。同梱分を含めた充足率が同じ場合は、譜面で使用するファイルが既に多くそろっている候補を優先するようにしました。

### インストール

- 設定画面の `インストール` → `導入先の自動推定` に `取り込み後の自動推定で導入先が確定したら、自動インストールする` を追加しました（既定はOFF）。
  - 有効にすると、取り込み時の自動推定が正常に完了した後、今回の推定で導入先が確定したパッケージを確認画面なしで導入します。
  - 手動で開始した推定や、既に保留されているパッケージは自動導入の対象外です。
- 保留ルートと個別パッケージの一覧上部に `推定`・`インストール`・`クリア` の操作バーを追加しました。
  - 譜面を選択し、右クリックメニューと同じ導入先の推定・推定先へのインストール・導入先のクリアを実行できるショートカットです。
- フォルダや書庫を取り込むときの保留パッケージの分け方を見直しました。
  - 差分ごとに別の音源を使っていても、previewや背景画像などを同梱するフォルダは1つのパッケージとして扱い、同梱ファイルも一緒にインストールします。
  - 同梱ファイルがなく別々の曲の差分を集めたフォルダは、譜面ごとに分けて曲ごとに推定・インストールします。
  - 同梱ファイルのない同じ曲の差分は、タイトルとアーティストが（難易度表記を除いて）揃えば1つのパッケージにまとめます。
- 保留画面の健康度とリソース不足警告を、設定した導入先、未設定なら先頭候補へ同梱リソースを配置した場合の状態で表示するようにしました。
  - WAV・BGA・MOVIEに加え、STAGEFILE・BACKBMP・BANNERも同じ基準で確認できます。導入先を設定した後も、不足があれば警告を表示します。
  - 推定対象全体の音源が導入後も不足する、または完全性を確認できず導入先の自動確定を見送った場合に、`導入後音源不足` / `導入後音源未確認` を表示し、行を警告色にするようにしました。
  - 保留画面から開く `譜面プロパティ` も同じ配置基準でリソースを確認し、確認基準と確認先を表示するようにしました。
- LR2連携で、最近追加した曲がない状態からインストールしたときも、アプリを再起動せずにLR2の新曲フォルダが表示されるようにしました。

### リソース健康度

- `WAV`・`BGA`・`MOVIE` の計算対象を、`#WAV`・`#BMP` の定義全体から、譜面内で使用が指定されたファイルへ変更しました。
  - 未使用の定義は数えず、同じファイルを複数の定義番号で参照していても1件として扱います。
- パーセンテージを「存在するファイル数 ÷ 使用するファイル数 × 100」に変更し、従来の不足時の追加減点をなくしました。
  - 例えば、使用ファイル4件のうち3件があれば75%です。
- 使用ファイルがない種類は `-` と表示します。定義のない参照番号による無音ノーツなどは、不足に含めません。

### 譜面プロパティ

- 一覧の右クリックメニューに `譜面プロパティ` を追加しました。
  - ローカルに実ファイルのある譜面を1件選んで開けます。
  - 保留パッケージ内の譜面にも対応しています。
  - BMS・PMS・bmsonの不足・確認不能なファイル、未使用リソース定義、未定義参照番号を確認できます。STAGEFILE・BACKBMP・BANNERなどの補助画像も不足確認の対象です。
  - BMS・PMSは `#WAV01 file.wav` などのコマンド風の表記で、bmsonは本来の項目名で表示します。表示された文字は選択してコピーできます。

### プレイリストのインポート

- プレイリストツリーのルートを右クリックして開く `プレイリストをインポート` に、難易度表リスト・内蔵表・URL／ファイルからの読み込みをまとめました。
  - 複数の入力元から選んだ表を右側の一覧で確認し、一度にインポートできます。
  - 難易度表を名前・記号・分類・URLの部分一致で検索できるようにしました。分類単位や検索結果全体の選択・解除、登録済みURLや同名候補の非表示にも対応しています。

### 設定

- 多くの設定を、項目の変更時に保存・反映する方式へ変更しました。
  - 音声やスコア取得元なども、有効な選択がそろうと設定画面を閉じずに反映されます。
  - BMSディレクトリやBMT出力、右クリック設定の各項目などは、確定ボタンで反映します。
- 動作モードやLR2ディレクトリの変更時は再起動を確認します。
  - `song.db`・`config.xml`の個別変更は `詳細` 内でまとめて確定し、1回の再起動で反映できます。
  - beatorajaディレクトリの変更は再起動せずに反映します。
- 詳細設定に分散していたインストール関連の設定と確認メッセージを `インストール` へ集約しました。
- 設定名と説明文を整理し、URL1/URL2列クリックでの自動取得と自動推定後の導入の違い、上書き・削除、確認メッセージの対象を分かりやすくしました。
- 設定画面の初回表示を改善し、各ページは初めて選んだときに準備するようにしました。ページを切り替えても編集中の入力を保持します。
- 利用開始に必要な設定に不備があると、設定画面の下部に `対応が必要な設定` を表示するようにしました。
  - 「ページ名: 理由」の項目から該当する欄へ移動でき、不備のあるページには印が付きます。
  - 起動時の確認で止まった場合も、警告に修正が必要な設定を表示します。
- スコアの使用、外部画像、BMT出力、外部プレイヤーは、必要なディレクトリやファイルが揃うまで保存せず、欄の下に理由を表示するようにしました。
- 音声デバイス一覧は音声ページを開いたときに取得するようにしました。取得中も他の設定の編集・保存・取消やページの切り替えを続けられます。
- 詳細設定の初期化設定に `起動時のソートキャッシュ準備範囲` を追加しました。`準備しない`・`基本のみ（既定）`・`標準`・`すべて` から選べ、変更は次回起動から適用されます。従来は `すべて` 相当の範囲を準備していました。事前生成しない列も、選択時には通常どおりソートできます。

### 外観テーマを追加

外観テーマを従来のライト・ダークから、全10種類に拡充しました。

新たに追加したテーマ：

- **セピア** — 温かみのある落ち着いた配色
- **フロスト** — 透明感のある寒色系の配色
- **ネオン・バイオレット** — 紫をアクセントにした鮮やかなダークテーマ
- **グリーンターミナル** — 昔の緑色モニターをイメージした配色
- **アンバーターミナル** — 琥珀色のレトロなターミナル風配色
- **OLEDブラック** — 純黒を基調としたダークテーマ
- **ディープシー** — 深海をイメージした青系のダークテーマ
- **DOSブルー** — クラシックなDOS画面をイメージした配色

### 一覧

- 左右キーで選択セルの移動が行えるようにしました。移動先のセルが編集・コピーの対象になります。
- 検索欄で候補を選んでいないときの `Enter` と `Tab` の動作を整理しました。`Enter` は入力したとおりに検索を確定します。`Tab` は項目名や値を1文字以上入力していれば先頭の候補で補完し、空欄や `:` の直後では次の項目へ移動します。

### 同時に実行できない操作の案内

- 別のライブラリ操作の実行中で開始できない操作を選んだときに、「別のライブラリ操作が実行中のため、操作を開始できません。」と案内するようにしました。従来は何も表示されずに実行されない場合や、エラーとして表示される場合がありました。
  - 対象は、譜面の削除・移動・自動リネーム・重複の整理、プレイリストのプロパティ・一括編集・セルの編集・削除、ライブラリの処理を伴う設定の確定、試聴の開始などです。
  - 同時に実行できない操作の組み合わせは、マニュアルの「同時に実行できない操作」にまとめました。

### 音声ファイルへの変換

- 保存形式のエンコーダーが見つからない場合、出力フォルダを指定する前に警告し、今回だけWAVEで続行するか中止するかを選べるようにしました。従来は通知なしでWAVEへ切り替えて変換し、設定の保存形式も書き換えていました。どちらを選んでも、設定の保存形式は変更しません。
- 完了通知に出力形式を表示するようにしました。進捗表示とともに、実際に使った形式を示します。

### ランプビューア

- Windowsの拡大縮小率がモニターごとに異なる環境で、メインウィンドウから離れた位置や画面外に開く問題を修正しました。
- メインウィンドウの中央を基準に開き、表示先の作業領域に合わせて位置と大きさを調整するようにしました。
- 拡大縮小率の異なるモニターへ移動した際に、文字の表示幅やグラフ内のラベルを更新するようにしました。選択・スクロール位置・表示モードは維持します。
- タスクバーからランプビューアを直接選択できるようにしました。

### 診断ログ

- 起動時のアプリ・Windowsのバージョンやモニター構成・拡大縮小率を `log/application.log` に記録し、表示の問題を調べやすくしました。
- 予期しないエラーの記録先をローカルのログへ統一し、自動送信を行わないようにしました。

# English

v3.2.0.0 makes installation destination estimation more accurate. Packages whose destinations are determined by automatic estimation after import can now be installed automatically.

Resource health is now calculated from the files actually used by each chart instead of the number of `#WAV` and `#BMP` definitions. Unused definitions are excluded, making the values more reliable.

This release also refines the UI in Settings, appearance themes, lists, the Lamp Viewer, and more.

> [!IMPORTANT]
> **Rescan charts to update saved resource health to the new calculation basis.**
>
> Updating the app does not automatically recalculate saved resource counts using the new used-file basis. As needed, run `File scan` → `Rescan all charts` to update them.

## Changes

### Installation Destination Estimation

- Removed `Estimate merge destination` and unified it with `Estimate install destination`. The same command can also estimate destinations for packages containing only charts you already own.
- Revised the estimation method so that main packages with many bundled resources and add-on charts with few bundled resources are evaluated in the same way. When availability including bundled resources is equal, candidates that already contain more of the files used by the chart are now preferred.

### Installation

- Added `Install automatically when estimation after import determines a destination` under `Install` → `Automatic destination estimation` in Settings (OFF by default).
  - When enabled, packages whose destinations were determined by the current import's automatic estimation are installed without a confirmation dialog after estimation completes successfully.
  - Manually started estimation and packages already pending are excluded from automatic installation.
- Added an operation bar with `Estimate`, `Install`, and `Clear` above the chart list for the Pending root and individual packages.
  - It is a shortcut: select charts to use the same destination estimation, installation to the estimated destination, and destination clearing actions as the context menu.
- Revised how imported folders and archives are split into pending packages.
  - A folder that bundles previews, background images, or other files is treated as one package even when each chart uses different key sounds, and the bundled files are installed together.
  - A folder of charts for different songs with no bundled files is split per chart, so each song is estimated and installed separately.
  - Charts for the same song with no bundled files are grouped into one package when their titles and artists match after difficulty labels are ignored.
- Resource health and missing-resource warnings in the pending view now reflect the configured destination, or the first candidate when no destination is set, including bundled resources that would be installed there.
  - The same basis applies to STAGEFILE, BACKBMP, and BANNER in addition to WAV, BGA, and MOVIE. Missing-resource warnings remain visible after setting a destination.
  - Added `Audio missing after installation` / `Audio after installation unverified` warnings and highlighted rows when automatic destination selection is withheld because audio would remain missing or its completeness cannot be verified for the estimated group.
  - `Chart properties` opened from the pending view uses the same resource placement basis and displays the verification basis and path.
- In LR2 mode, installing a song when no songs were recently added now shows LR2's new song folder without restarting the app.

### Resource Health

- `WAV`, `BGA`, and `MOVIE` now count files used by the chart rather than all `#WAV` and `#BMP` definitions.
  - Unused definitions are excluded, and the same file is counted once even when referenced through multiple definition numbers.
- Percentages now use “existing files ÷ used files × 100,” without the previous additional penalty for missing files.
  - For example, three existing files out of four used files gives 75%.
- Categories with no used files display `-`. Undefined reference numbers, such as those used for silent notes, do not count as missing files.

### Chart Properties

- Added `Chart properties` to the list context menu.
  - Select one chart with a local file to open it.
  - Charts inside pending packages are also supported.
  - Inspect missing or unverifiable files, unused resource definitions, and undefined reference numbers in BMS, PMS, and bmson charts. Auxiliary images such as STAGEFILE, BACKBMP, and BANNER are also checked for missing files.
  - BMS and PMS entries use command-style notation such as `#WAV01 file.wav`, while bmson entries use their native field names. Displayed text can be selected and copied.

### Playlist Import

- Combined the table list, built-in tables, and URL / file input in the `Import playlists` window, opened from the playlist tree root's context menu.
  - Review tables selected from multiple sources in the list on the right and import them together.
  - Added substring search by table name, symbol, category, or URL. You can select or clear a category or all search matches, and hide registered URLs or candidates with existing names.

### Settings

- Most settings are now saved and applied when each item is changed.
  - Audio and score source selections also take effect once a valid combination is selected, without closing Settings.
  - BMS directories, BMT output, individual context menu actions, and similar settings are applied with confirmation buttons.
- Changing the operation mode or LR2 directory prompts for a restart.
  - Individual changes to `song.db` and `config.xml` can be confirmed together under `Details` and applied with a single restart.
  - Changes to the beatoraja directory take effect without restarting.
- Moved installation settings and confirmation messages from Advanced settings to `Install`.
- Clarified setting labels and descriptions, including the distinction between automatic retrieval from URL1/URL2 cell clicks and installation after automatic estimation, the handling of overwrites and deletion, and which operations display confirmation messages.
- Improved the initial opening of Settings. Each page is prepared when first selected, and edits are preserved when switching pages.
- Settings now shows `Settings that need attention` at the bottom when a setting required to start using the library has a problem.
  - Each "Page: reason" entry takes you to the field, and pages with problems are marked.
  - When the startup check stops, the warning also lists the settings that need correction.
- Using scores, external images, BMT output, and external players are no longer saved until the required directory or file is available, and the reason is shown below the field.
- Audio devices are now loaded when opening the Audio page. You can continue editing, saving, or canceling other settings and switching pages while the list loads.
- Added `Startup sort cache preparation` to the initialization section in Advanced settings. Choose `None`, `Basic only (default)`, `Standard`, or `All`; changes apply from the next application start. Previous versions prepared the equivalent of `All`. Columns that are not prepared can still be sorted normally when selected.

### More Appearance Themes

Expanded the appearance theme selection from Light and Dark to **10 themes**.

Eight new themes are available:

- **Sepia** — A warm, subdued color palette
- **Frost** — A cool, crisp color palette
- **Neon Violet** — A vibrant dark theme with purple accents
- **Green Terminal** — Inspired by vintage green monochrome monitors
- **Amber Terminal** — A retro terminal look with amber tones
- **OLED Black** — A dark theme built around pure black
- **Deep Sea** — A deep-blue dark theme inspired by the ocean
- **DOS Blue** — Inspired by classic DOS screens

### Lists

- Left / Right now moves the selected cell. Editing and copying use the destination cell.
- Clarified `Enter` and `Tab` in the search box when no suggestion is selected. `Enter` confirms the search as typed. `Tab` completes the first suggestion if you have typed at least one character of a field name or value, and moves to the next control on blank input or right after `:`.

### Notice for Operations That Cannot Run Together

- Choosing an operation that cannot start because another library operation is running now shows "Another library operation is in progress." Previously, such operations could be skipped without any message or appear as errors.
  - This applies to deleting, moving, auto-renaming, and duplicate cleanup of charts, playlist properties, bulk edits, cell edits, and deletions, confirming settings that require library processing, starting a preview, and similar operations.
  - The combinations that cannot run together are summarized under "Operations That Cannot Run Together" in the manual.

### Audio Conversion

- When the encoder for the saved file type cannot be found, a warning now appears before you choose the output folder, and you can continue as WAVE for this conversion only or cancel. Previously, the conversion switched to WAVE without notice and also rewrote the saved file type. Either choice leaves the saved file type in Settings unchanged.
- The completion message now shows the output format. Together with the progress display, it shows the format actually used.

### Lamp Viewer

- Fixed the viewer opening far from the main window or off-screen when Windows display scaling differs between monitors.
- The viewer opens centered on the main window, with its position and size adjusted to fit the destination monitor's work area.
- Text measurements and labels inside graphs now update when moving the viewer between monitors with different scaling settings. Selection, scroll position, and display mode are preserved.
- The viewer can now be selected directly from the taskbar.

### Diagnostic Logs

- App and Windows versions, monitor configuration, and display scaling are now recorded in `log/application.log` at startup to help investigate display issues.
- Unexpected errors are now recorded in local logs without automatic transmission.
