# 日本語 v1.2.1.0

## 機能・操作面の変更

### インストール / 保留パッケージ

- 保留パッケージの再統合機能を追加しました。
  - フォルダごとドロップして走査した結果、同一フォルダ内で分割された譜面群について、導入先が同じと判定された場合は 1 つの保留パッケージとして扱うようになりました。
  - これにより、同一作品の差分譜面群が個別の単体 BMS として並ぶケースでも、フォルダ単位で扱いやすくなります。
  - 今回は特に [Stella Uploader のこの差分](https://stellabms.xyz/upload/7475) のような配布形態に対応するための改善です。
  - 従来は「BMS が 1 個だけである」「実在する WAV/BGA を持つ」「譜面間で参照リソース名の共通率が高い」といった条件に当てはまる場合にだけ、同一フォルダを 1 つのパッケージと見なしていました。
  - この差分は同一フォルダ内に複数の BMS を含みつつ、譜面ごとに異なるキー音を使っていて共有リソース名も少なかったため、従来条件では同一パッケージと判定されず、単体 BMS として分割されていました。
- 再統合の適用条件を安全側に調整しました。
  - 再統合は「フォルダ全体を走査した結果として作られた分割状態パッケージ」に限定されます。
  - 同じフォルダ内の BMS を個別に選択して追加した場合や、1 つずつ保留へ追加した場合は自動再統合されません。

## 不具合修正 / 安定性向上

- 通常インストール後の元フォルダ削除を安全化しました。
  - `インストール後、元パッケージを削除する` が有効な場合でも、元フォルダが空になるか、残存ファイルが既所持譜面のみと確認できた場合にだけ削除します。
  - 非譜面ファイル、未所持譜面、判定不能なファイルが残る場合は元フォルダを保持します。
- 保留パッケージ再統合後の warning 表示を調整しました。
  - `BMSファイル単体です` のような単体前提の warning が残らないようにし、再統合後のパッケージ形状に合わせて warning を再評価します。
- 保留パッケージ再統合まわりの回帰テストを追加し、手動追加時の誤統合と、フォルダ走査由来の正しい再統合の両方を確認できるようにしました。
- 上記の差分を過去バージョンで導入している場合、意図どおりに取り込めていない可能性があります。
  - [https://stellabms.xyz/upload/7475](https://stellabms.xyz/upload/7475) から対象差分を再取得し、再インストールすることをおすすめします。

# English v1.2.1.0

## Feature and usability changes

### Install / pending packages

- Added regrouping for pending packages.
  - When a whole folder is dropped and scanned, split charts from the same source folder are now regrouped into a single pending package if their install destination resolves to the same directory.
  - This makes it easier to handle differential chart sets that would otherwise appear as separate single-file BMS entries.
  - This change specifically targets distribution styles such as [this Stella Uploader differential package](https://stellabms.xyz/upload/7475).
  - Previously, a folder was treated as a single package only when it matched conditions such as having exactly one BMS, having charts with existing WAV/BGA resources, or having a high overlap in referenced resource names across charts.
  - This differential package contains multiple BMS files in one folder, but each chart uses different key sounds and shares only a small amount of resource-name overlap, so it did not meet the old single-package conditions and was split into separate single-file BMS entries.
- Tightened the regrouping condition to the safer side.
  - Regrouping now applies only to split packages created from a full folder scan.
  - Charts added individually from the same folder, or added one by one over time, are no longer regrouped automatically.

## Bug fixes / stability improvements

- Made post-install source folder deletion safer.
  - Even when `Delete source package after install` is enabled, the source folder is deleted only if it becomes empty or if the remaining files are confirmed to be already-installed charts.
  - If any non-chart file, not-yet-installed chart, or unresolvable file remains, the source folder is kept.
- Adjusted warning handling after pending-package regrouping.
  - Single-file warnings such as `BMS file only` are no longer left behind after regrouping, and warnings are recalculated to match the regrouped package shape.
- Added regression tests around pending-package regrouping so both safe non-regroup behavior for manual additions and correct regroup behavior for folder-scan cases are covered.
- If this differential package was installed on an older version, it may not have been imported as intended.
  - Re-downloading it from [https://stellabms.xyz/upload/7475](https://stellabms.xyz/upload/7475) and reinstalling it is recommended.
