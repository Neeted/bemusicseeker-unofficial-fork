# 日本語

## 変更点

## 不具合修正 / 安定性向上

- プレイリスト詳細の複数行選択メニュー `選択中の本体URLを取り込む` / `選択中の差分URLを取り込む` の URL 解決と導入処理を改善しました。
  - MediaFire などの既知の配布ページでは、URL 末尾の `.zip` / `.7z` などの拡張子より配布ページ解析を優先し、HTML ページをアーカイブとして誤って取り込まないようにしました。
  - `venue.bmssearch.net` の作品ページで、イベント全体のパッケージではなく作品個別の本体 URL を優先して取り込むようにしました。
  - Google Drive / MediaFire などで、ページ解析後に同じファイルへ解決された URL は重複ダウンロードしないようにしました。
  - Google Drive から取得したファイル名の日本語が文字化けする場合があった問題を修正しました。
  - URL 取り込みとアーカイブ解凍のログを強化し、導入中に時間がかかった場合の原因を追跡しやすくしました。
  - ダウンロード後のアーカイブ解凍中に、現在何個目のアーカイブを処理しているかを進捗表示に出すようにしました。大量の URL を取り込む際に、導入処理が止まって見えにくくなります。
  - URL 取り込み中にキャンセルできるようにしました。キャンセルした場合も、それまでに取得できたファイルは導入キューへ渡します。
  - URL 取り込み結果にキャンセルで未処理になった件数を表示し、ダウンロード失敗時のログも詳しくしました。


# English

## Changes

## Bug Fixes / Stability

- Improved URL resolution and installation for the multi-row playlist actions `Import selected original URLs` / `Import selected diff URLs`.
  - For known download pages such as MediaFire, the app now resolves the page before trusting `.zip` / `.7z` suffixes, preventing HTML pages from being imported as archives.
  - `venue.bmssearch.net` entry pages now prefer the entry-specific download URL instead of event-wide package URLs.
  - URLs that resolve to the same Google Drive / MediaFire file are now skipped as duplicates after resolution.
  - Fixed mojibake in some Japanese filenames downloaded from Google Drive.
  - Added more detailed logs for URL import and archive extraction to make long-running installation steps easier to diagnose.
  - Archive extraction now shows which archive is currently being processed after downloads complete, making large URL imports less likely to look stalled.
  - Playlist URL import can now be canceled during downloads. Files downloaded before cancellation are still passed to the install queue.
  - The URL import result now shows how many targets were skipped by cancellation, and download failure logs include more detail.
