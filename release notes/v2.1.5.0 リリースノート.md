# 日本語

## 変更点

### beatoraja 連携

- 設定画面の beatoraja 連携に「beatoraja の Table URL をインポートする」を追加しました。beatoraja の `config_sys.json` に登録済みの `tableURL` を BeMusicSeeker のプレイリストへ取り込み、元の並びを `BMT SORT` に反映できます。
- Table URL インポート時の外部難易度表取得を並列化し、登録後の参照更新や `.bmt` 出力予約をまとめて行うようにしました。
- Table URL インポートでは `config_sys.json` に書かれていた URL 文字列を正本として扱い、後続の `.bmt` 出力にもその URL を反映します。
- `.bmtを出力する` を有効にする前に beatoraja の Table URL を取り込むと、beatoraja 選曲画面での難易度表の並びを維持しやすくなり、beatoraja 側での難易度表リロードを減らせます。
- beatoraja Table URL インポート時、外部から読み込めない難易度表は beatoraja の `tablepath` 配下にある `.bmt` キャッシュから復元を試みるようにしました。復元できない URL は BeMusicSeeker 管理外として扱い、既存の `tableURL` 先頭側に残します。
- Table URL から取り込んだ難易度表が一時的に空で `.bmt` を出力できない場合でも、BeMusicSeeker 管理の Table URL として扱い、`BMT SORT` 順に配置されるようにしました。

### プレイリスト

- `URLを指定して読み込む` の複数行インポートを並列・バッチ処理にし、複数の外部難易度表をまとめて読み込む際の待ち時間と後処理の空白時間を減らしました。
- 複数行インポート時に同名プレイリストがあっても処理全体を途中停止せず、その URL だけをスキップして完了後に件数と対象名を表示するようにしました。

## 不具合修正 / 安定性向上

- 設定画面の `テスト再生 & レイテンシ計測` で使用するテスト音声ファイルが配布パッケージに含まれていなかった問題を修正しました。

# English

## Changes

### beatoraja Integration

- Added `Import beatoraja Table URLs` to the beatoraja integration settings. It imports `tableURL` entries from beatoraja `config_sys.json` into BeMusicSeeker playlists and reflects the original order in `BMT SORT`.
- Table URL import now loads external difficulty tables in parallel and batches post-registration reference updates and `.bmt` export scheduling.
- Table URL import treats the URL string written in `config_sys.json` as the source of truth and reflects that URL in later `.bmt` output.
- Importing beatoraja Table URLs before enabling `.bmt output` makes it easier to preserve difficulty table order on beatoraja's song-select screen and reduces the need to reload difficulty tables in beatoraja.
- When beatoraja Table URL import cannot load a table externally, it now tries to restore the table from the `.bmt` cache under beatoraja `tablepath`. URLs that still cannot be restored remain unmanaged by BeMusicSeeker and stay at the front of the existing `tableURL` list.
- If a Table URL imports as a temporarily empty table that cannot produce a `.bmt` file, BeMusicSeeker still treats its Table URL as managed and places it according to `BMT SORT`.

### Playlists

- Multi-line `Load by specifying URL` imports now use parallel loading and batched post-processing, reducing wait time and the quiet period after external difficulty table downloads finish.
- When a duplicate playlist name is found during multi-line import, BeMusicSeeker now skips only that URL, continues processing the remaining URLs, and shows the skipped count and names after completion.

## Bug Fixes / Stability

- Fixed a missing bundled test audio file used by `Test playback & latency measure` in the settings dialog.
