# 開発資料

`devdocs/` の文書を作成・編集する前に `dev-docs` スキルを呼び、注入された[書き方](../../devdocs/README.md#書き方)と[現行情報の維持](../../devdocs/README.md#現行情報の維持)に従います。この会話で呼出し済みでも、会話の圧縮後は呼び直します。読むだけの場合は不要です。

見出しを変更・移動するときは、`.claude/` 配下（スキル、担当定義、ルール、フック）と `CLAUDE.md` がその見出しを参照していないか検索し、同じ変更で更新します。
