# 表示リソース

表示文言を追加・変更するときは、`AGENTS.md` の「ログと表示文言」を読み直し、そこに挙げたリソースと全言語のファイルを同じ変更で揃えます。

辞書の整合と実際の表示の検査は、[表示リソースの検査](../../devdocs/spec/development/test-authoring.md#表示リソースの検査)に従います。
