# BeMusicSeeker 依存ライブラリ ライセンス調査報告

本プロジェクトを **MITライセンス** として公開し、かつリリースパッケージ（ビルド成果物）に依存DLLを含めて配布する場合のライセンス上の懸念点および各ライブラリのライセンス形態を調査した結果です。

## 全体サマリー
本プロジェクト自体をMITライセンスとしてソース公開すること自体は問題ありません。
ただし、**いくつかのサードパーティ製DLLはMITライセンスと互換性のない（または制約のある）ライセンス**で提供されているため、パッケージに同梱して再配布する際には注意が必要です。

特に **BASS (un4seen)** に関しては、商用利用時のライセンス制約があるため重要です。

## MITライセンスで公開するための推奨アクション

1. **プロジェクト全体のライセンス設定**
   ソースコードのルートディレクトリに `LICENSE` または `LICENSE.txt` としてMITライセンスの全文を配置します。

2. **サードパーティライセンスの明記 (Third-Party Notices)**
   `CREDITS.md` や `ThirdPartyNotices.txt` のようなファイルを作成し、上記で使用している各DLLの著作権表記とライセンス（特に MIT, BSD, zlib, LGPL の表記）を列挙して同梱します。

3. **BASSライセンスの例外条項の追記（超重要）**
   READMEに以下のような趣旨の免責事項を必ず記述してください。
   > 本ソフトウェア (BeMusicSeeker) のソースコードはMITライセンスの元で公開されていますが、音声再生エンジンとして使用している **BASS Audio Library (un4seen developments)** はMITライセンスではありません。非商用目的でのみ無料で利用・配布が許可されています。本ソフトウェアを派生させて商用利用を行う場合は、Un4seen社より適切なBASSの商用ライセンスを取得する必要があります。

この対応により、本プロジェクトを「MITライセンスのオープンソースプロジェクト」として合法かつ安全にリリース・配布することが可能です。
