キーワード検索ガイド

BeMusicSeeker の検索欄では、曲名やアーティスト名などをすばやく絞り込めます。検索対象を指定したり、複数の条件を組み合わせたりすることもできます。

このガイドの検索方法は、主に次の画面で利用できます。

  • メインの譜面一覧
  • プレイリスト詳細
  • プレイリスト一覧
  • プレイログ

画面によって利用できる検索対象は異なります。入力できる検索対象は、検索欄に表示される候補からも確認できます。

まず試す検索例

やりたいこと 入力例
alpha を含む譜面を探す alpha
TITLE と ARTIST を指定する title:alpha artist:xi
レベル 10～12 に絞る level:10..12
backup フォルダを除外する -path:backup
特定のプレイリストを参照している譜面を探す playlist:"Satellite Sub"
指定日のプレイログを表示する date:2026-08-27

複数の条件を半角スペースで区切ると、すべての条件に一致する行だけが表示されます。

検索候補・お気に入り・検索履歴

検索欄を選ぶと、入力内容に応じて候補が表示されます。

入力していないとき

検索欄が空のときは、登録されている内容に応じて次の順に表示されます。

  1. お気に入り
  2. 検索履歴
  3. 検索対象

お気に入りと検索履歴はそれぞれ最大5行の高さで表示され、6行目以降はスクロールして確認できます。検索対象は最大10行の高さで表示されます。

入力を始めたとき

検索対象名を入力すると、現在の画面で利用できる候補に絞り込まれます。

t

メインの譜面一覧とプレイリスト詳細では、table:、tag:、title: などが候補になります。除外条件の - を付けたままでも候補を利用できます。

-ar

この例では -artist: を選べます。

値の種類が決まっている検索対象では、: の後に検索値の候補が表示されます。

clear:
rank:
feature:

候補を選ぶと値の後ろに半角スペースが入り、そのまま次の条件を入力できます。title: のように自由な文字列を入力する検索対象では、検索値の候補は表示されません。

playlist:、ref:、table: では、登録済みのプレイリスト名から候補を選べます。

playlist:Sat

候補を選ぶと、必要に応じてプレイリスト名がダブルクォートで囲まれます。

playlist:"Satellite Sub"

検索対象と検索値は最大10行の高さで表示され、11行目以降はスクロールして確認できます。

お気に入りを使う

検索履歴の右端にある［お気に入りに追加］を押すと、その検索をお気に入りへ登録できます。お気に入りの右端にある［お気に入りから削除］を押すと解除できます。

  • お気に入りの登録数に上限はありません。
  • お気に入りへ追加・削除しても、検索欄に入力中の内容は変わりません。
  • 同じ検索が検索履歴にも残っている場合は、お気に入りにだけ表示されます。お気に入りから削除すると、履歴が残っていれば検索履歴へ戻ります。

メインの譜面一覧、プレイリスト詳細、プレイログでは同じお気に入りを共有します。プレイリスト一覧のお気に入りは別に保存されます。現在の画面で使えない検索対象を含むお気に入りや検索履歴は、その画面では表示されませんが削除はされません。

検索履歴を使う

入力後に Enter を押すか、検索欄から別の場所へ移ると、検索が履歴へ保存されます。お気に入りまたは検索履歴を選ぶと、検索欄全体がその内容に置き換わり、使用した検索として履歴の先頭へ移動します。

  • 検索履歴は新しい順に最大20件まで保存されます。
  • 同じ検索をもう一度使うと、重複せず先頭へ移動します。
  • 右端の［検索履歴から削除］で不要な履歴を削除できます。

検索履歴も、メインの譜面一覧・プレイリスト詳細・プレイログで共有され、プレイリスト一覧では別に保存されます。

キーボードで操作する

操作 結果
↑ / ↓ 候補を選ぶ
Enter / Tab 選択中の候補を入力する
Esc 候補を閉じる
Ctrl+Space 候補をもう一度開く
Shift+Tab 選択中のお気に入り・履歴行の操作ボタンへ移動する

操作ボタンへ移動した後は、Tab / Shift+Tab でボタンを移動し、Enter または Space で実行できます。日本語入力の変換確定に使った Enter では候補は選択されません。

基本的な検索方法

文字をそのまま検索する

検索語を入力すると、対象となる情報のどこかにその文字列を含む行が表示されます。大文字・小文字は区別しません。

alpha

複数の検索語を半角スペースで区切ると、すべての語に一致する行だけが表示されます。

alpha artist

検索対象を指定する

検索対象:検索語 の形で、探す場所を限定できます。

title:alpha
artist:xi
sha256:abcdef

複数の条件を並べると AND 検索になります。

title:alpha artist:xi

D:\BMS\ のようなドライブ文字を含む文字列はパスとして検索できます。

スペースを含む文字列を検索する

スペースを含む文字列はダブルクォートで囲みます。

"alpha title"
title:"alpha title"

一致する行を除外する

条件の先頭に - を付けます。

alpha -artist:beta
-path:backup

いずれかに一致する行を探す

1つの条件の中で | を使います。

alpha|beta
title:alpha|beta

title:alpha|artist:beta のように、異なる検索対象をまたぐ OR 検索はできません。条件を分けて入力した場合は AND 検索になります。

検索対象を指定しない場合は、TITLE、ARTIST、PATH、FOLDER欄、参照プレイリスト名、各ハッシュ値、TYPE、クリア状態、取得元、プレイ日付などを検索します。

プレイログでは、level、difficulty、notes、rank、rate、score、bp など、譜面一覧用の検索対象は利用できません。

上部のサマリーカードと検索欄は組み合わせて利用できます。たとえば SCORE 更新カードを選んだ状態は type:score、EASY カードは type:clear newclear:EC に相当します。検索欄の条件とは AND、複数のカード同士は OR で絞り込まれます。

数値・状態・日付で絞り込む

数値を比較する

数値を扱う検索対象では、範囲や比較演算子を利用できます。

level:10..12
notes:>=2000
duration:<120
tn:2.0..
rate:0.95..
bp:0..10
  • 10..12: 10以上12以下
  • >=2000: 2000以上
  • <120: 120未満
  • 2.0..: 2.0以上

情報の有無を検索する

値が登録されている行は defined、登録されていない行は undefined で検索できます。undefined は undef と書くこともできます。

total:undefined
difficulty:defined
score:defined
rank:undefined

譜面解析やスコアの情報がまだない場合は undefined に一致します。メインの譜面一覧とプレイリスト詳細では、clear は NO SONG や NO PLAY も1つの状態として扱うため、clear:undefined には一致しません。プレイログの clear:defined は、更新後のクリア状態が記録されている行を表示します。

候補から選べる主な検索値

検索対象 主な検索値
difficulty beginner、normal、hyper、another、insane
judge veryhard、hard、normal、easy、veryeasy
feature ln、mine、random、lnmode、cn、hcn、stop、scroll
rank / djlevel / dj F、E、D、C、B、A、AA、AAA、MAX
プレイログの type / kind score、bp、clear、combo、play
プレイログの finalized true、false

値の有無を検索できる対象では、これらに加えて defined と undefined も候補に表示されます。

クリア状態を検索する

clear、oldclear、newclear では表示名のほか、次の短縮表現を利用できます。

clear:HC

プレイ日時を検索する

プレイログでは、日付、日時、期間を指定できます。

特定の日時を探す場合は、DATE欄の表示をコピーし、ダブルクォートで囲んで先頭に date: を付ける方法が簡単です。

date:2026-08-27
date:2026/8/27
date:20260827
date:"2026/08/27 10:22:50"
date:"2026/08/27 10:22:50..2026/08/27 11:04:12"

期間検索では、開始日時と終了日時のプレイも結果に含まれます。

プレイログで2行以上を選択して右クリックし、［検索に期間を追加］を選ぶと、選択した最も早い日時から最も遅い日時までの条件を検索欄へ追加できます。すでに入力してある条件は残ります。

高度な検索

正規表現

re: に続けて正規表現を入力します。検索対象や除外条件とも組み合わせられます。

re:^alpha
title:re:^alpha
-title:re:^test
path:re:\\BMS\\.*\.bms$

正規表現は大文字・小文字を区別しません。処理に時間がかかりすぎる式は途中で停止し、その条件には一致しなかったものとして扱われます。

ダブルクォート内で " や \ を検索する

ダブルクォート内では、\" で "、\\ で \ を表します。

title:"alpha \"quoted\""

通常の文字列検索では、閉じるダブルクォートを省略すると、入力の末尾までが1つの検索語として扱われます。date: で日時や期間を囲む場合は、閉じるダブルクォートも入力してください。

警告が表示される・結果が0件になる場合

次のような条件は警告の対象となり、検索結果には一致しません。

入力例 確認すること
unknown:alpha その画面で利用できる検索対象か
title: : の後に検索語があるか
- - の後に除外条件があるか
| | の前後に検索語があるか
title:re:[ 正規表現が正しいか
date:2026-99-99 日付の書式が正しいか

検索対象は画面ごとに異なります。迷った場合は検索欄を空にし、［検索対象］に表示される候補から選んでください。
